## 1. 微积分

研究"变化"的数学，是优化与训练的基础。

- **极限与连续**：理解"无限逼近"的思想
- **导数 / 偏导数**：函数对某个变量变化的敏感度
- **梯度 $\nabla f$**：多元函数上升最快的方向——训练神经网络的核心
- **链式法则**：复合函数求导，**反向传播**的数学原理
- **积分**：求面积 / 累积量，概率密度归一化要用

## 2. 线性代数

数据与模型的"语言"——一切都是向量和矩阵。

- **标量 / 向量 / 矩阵 / 张量**：数据的组织形式
- **矩阵乘法**：线性变换，神经网络每一层的本质
- **转置、逆、秩**：刻画矩阵的结构
- **范数**：$\ell_1$（稀疏）、$\ell_2$（能量 / 误差）度量"大小"
- **特征值与特征向量**：稳定性、主方向
- **矩阵分解（PCA / SVD）**：降维与压缩

## 3. 概率与统计

在**不确定性**下推理与决策的工具。

- **随机变量与概率分布**：离散 / 连续；正态、伯努利、泊松
- **期望、方差、协方差**：中心、波动、联动
- **条件概率与贝叶斯定理**：用新证据更新信念
- **大数定律与中心极限定理**：为什么"平均"和"正态"无处不在
- **估计**：极大似然 (MLE)、最大后验 (MAP)
- **假设检验与置信区间**：判断"差异是否显著"

## 4. 优化

"学习 = 最小化损失"，优化是连接数学与机器学习的桥梁。

$$\theta^\* = \arg\min_\theta \; \mathcal{L}(\theta)$$

- **凸 vs 非凸**：是否存在唯一全局最优
- **梯度下降**：沿负梯度迭代下降，$\theta \leftarrow \theta - \eta\,\nabla\mathcal{L}$
- **随机 / 小批量梯度下降 (SGD)**：用小批样本估计梯度
- **约束优化与拉格朗日乘子**：带限制条件的最优化

## 5. 信息论

衡量"信息量"与"分布差异"，深度学习损失函数的来源。

- **熵 (entropy)**：不确定性的度量
- **交叉熵 (cross-entropy)**：分类任务最常用的损失
- **KL 散度**：两个分布的"距离"
- **互信息**：两个变量共享多少信息
