Linear ARIMA struggled with many real problems (finance, signals, control), so researchers turned to **nonlinear** and **data-driven** methods. Rising computing power revived neural networks, and recurrent neural networks (RNNs) were used to process sequences — but people soon ran into a wall: vanishing gradients when training on long sequences.

## Key contribution 1: recurrent neural networks (RNNs)

How can a model be given "memory", so that it can handle dependencies across sequences of arbitrary length?

An RNN carries historical information in a recursively updated hidden state $$h_t$$:

$$ h_t = \tanh\!\big(W_{hh}h_{t-1} + W_{xh}x_t + b_h\big),\qquad \hat y_t = W_{hy}h_t + b_y $$

The hidden state $$h_t$$ depends on both the previous state $$h_{t-1}$$ and the current input $$x_t$$, so in theory information from arbitrarily far back can be passed all the way along. The same set of weights $$W$$ is shared across all time steps, which lets the network handle sequences of variable length.

Training uses backpropagation through time (BPTT), in which the gradient is multiplied through many time steps:

$$ \frac{\partial h_t}{\partial h_{t-k}} = \prod_{i=0}^{k-1}\frac{\partial h_{t-i}}{\partial h_{t-i-1}} $$

Every factor in this product contains weights and a $$\tanh$$ derivative. If they are generally smaller than 1, the product **decays exponentially** with $$k$$ (vanishing gradients), and long-range dependencies cannot be learned; if they are greater than 1, it explodes exponentially. This is the mathematical root of why RNNs struggle to capture long dependencies.

## Key contribution 2: LSTM (Hochreiter & Schmidhuber, 1997)

How can gradients be kept from vanishing over long sequences, so that long-term dependencies are truly learned?

Introduce a **cell state** $$c_t$$ as an information highway, and use three **gates** to control writing, retaining and reading information:

$$
\begin{aligned}
f_t &= \sigma(W_f[h_{t-1},x_t]+b_f) & &\text{(forget gate)}\\
i_t &= \sigma(W_i[h_{t-1},x_t]+b_i),\quad \tilde c_t = \tanh(W_c[h_{t-1},x_t]+b_c) & &\text{(input gate)}\\
c_t &= f_t\odot c_{t-1} + i_t\odot \tilde c_t & &\text{(cell update)}\\
o_t &= \sigma(W_o[h_{t-1},x_t]+b_o),\quad h_t = o_t\odot\tanh(c_t) & &\text{(output gate)}
\end{aligned}
$$

The key is $$c_t = f_t\odot c_{t-1} + i_t\odot\tilde c_t$$: the forget gate $$f_t\in(0,1)$$ decides how much old memory to keep, and the input gate $$i_t$$ decides how much new information to write. When $$f_t\approx 1$$ and $$i_t\approx 0$$, $$c_t\approx c_{t-1}$$ — the cell state is passed along as an approximate **identity**, and gradients along this path barely decay (the "constant error carousel"), so long-term dependencies are preserved. The gates are **learned adaptively** from data: the model itself decides when to remember, when to forget and when to read. $$\odot$$ denotes element-wise multiplication.

LSTM made learning on long sequences possible. It went on to dominate speech recognition and machine translation, and in the 2010s it was introduced at scale into time series forecasting, becoming the starting point of deep forecasting.

The 1990s established the paradigm of "learning sequences end to end from data with neural networks" and solved the long-dependency problem with gating — setting the stage for the deep learning revolution of the following decade.
