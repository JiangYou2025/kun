> 出自[数学基础](../math/) · [基础课总览](../)

梯度是多元函数对各个变量的**偏导数组成的向量**，它指向函数**上升最快**的方向，其长度表示上升有多陡。[优化](../optimization/)时沿它的反方向走，就能让函数下降。

## 直观理解

一元函数的"导数"是一个数（斜率）。但模型有成千上万个参数，函数是**多元**的——这时"斜率"不再是一个数，而是一个**向量**，告诉你"往哪个方向走、上升最快"。

站在一座山上，梯度就像一个箭头：箭头**指向最陡的上坡方向**，箭头**越长说明坡越陡**。要下山就朝箭头的反方向走。当你站到谷底（极小值）时，四面八方都不再上升，箭头长度变成 0——这就是"梯度为零"。

## 数学表达

对于 $f(x_1,x_2,\dots,x_n)$，梯度是各**偏导数**拼成的向量：

$$
\nabla f=\left(\frac{\partial f}{\partial x_1},\frac{\partial f}{\partial x_2},\dots,\frac{\partial f}{\partial x_n}\right)
$$

- $\dfrac{\partial f}{\partial x_i}$ —— **偏导数**：只让 $x_i$ 变、其余变量固定时函数的变化率；
- $\nabla$（nabla）—— 梯度算子；
- 梯度的**方向**是函数增长最快的方向，**模长** $\lVert\nabla f\rVert$ 是该方向上的最大变化率。

一个关键性质：梯度**垂直于等高线**（等值面）。因为沿等高线走函数值不变，而梯度指向变化最快的方向，二者自然正交。

## 一个具体例子

设 $f(x,y)=x^2+3y^2$。分别对 $x$、$y$ 求偏导：

$$
\frac{\partial f}{\partial x}=2x,\qquad \frac{\partial f}{\partial y}=6y
$$

$$
\nabla f=(2x,\ 6y)
$$

在点 $(1,1)$ 处，$\nabla f=(2,6)$：说明在这一点 $y$ 方向比 $x$ 方向陡得多（因为 $y$ 的系数大）。要下降，就朝 $(-2,-6)$ 方向走。在最优点 $(0,0)$，梯度为 $(0,0)$。

```python
import numpy as np
def grad(x, y):
    return np.array([2*x, 6*y])
print(grad(1, 1))   # [2 6]  上升最快方向
print(grad(0, 0))   # [0 0]  最优点，梯度为零
```

## 为什么重要 / 用在哪

- **优化的方向盘**：[梯度下降](../gradient-descent/) 用 $-\nabla L$ 决定每步往哪走。
- **[反向传播](../backpropagation/)**：用[链式法则](../chain-rule/)高效计算[损失](../loss-function/)对每个参数的梯度。
- **几何洞察**：梯度垂直于等高线，解释了为什么在狭长山谷里梯度下降会"之字形"震荡。

## 在时间序列预测中的意义

- 训练 KUN（Kernel U-Net）时，框架自动求出损失对每个权重的梯度，再交给[优化器](../optimizer/)更新——梯度是"模型该如何改进"的精确指令。
- 长序列深层网络中，梯度可能在反传时**消失或爆炸**（很多导数连乘的结果），残差连接、归一化、梯度裁剪都是为了让梯度健康地流动。

## 常见误区

- 梯度是**向量**，有方向有大小，别和一元导数（标量）混为一谈。
- 梯度指向**上升**最快方向，下降要取**负**梯度。
- 梯度为零只代表"驻点"，可能是极小、极大或鞍点，需结合二阶信息判断。
