**监督学习（supervised learning）** 指的是：训练数据里每个样本都带着“标准答案”（标签），模型的任务就是学会一条从**输入**到**输出**的映射规则，从而在见到新输入时也能给出正确的输出。

## 直观理解

想象一个学生在做练习册：每道题旁边都印着**正确答案**。学生先看题（输入），写下自己的答案，再对照标准答案，发现错了就调整思路。做的题越多，下次遇到类似的题就越准。

监督学习就是这个过程：

- **题目** = 输入特征 $x$（比如房子的面积、房间数）。
- **标准答案** = 标签 $y$（比如房子的真实成交价）。
- **学生的解题思路** = 模型 $f$。
- **对答案、纠错** = 用**[损失函数](../loss-function/)**衡量误差，再调整模型。

关键点在于：必须有人（或某种来源）事先把答案准备好。没有标签，就不是监督学习——那叫[无监督学习](../unsupervised-learning/)。

## 数学表达

我们手里有一份带标签的**数据集**：

$$
\mathcal{D} = \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}
$$

其中每个 $x_i \in X$ 是输入（可以是一个数，也可以是一个向量），每个 $y_i \in Y$ 是对应的正确输出。目标是学到一个函数：

$$
f: X \to Y
$$

使得 $f(x_i)$ 尽量接近 $y_i$。怎么衡量“接近”？用**损失函数** $L(\hat{y}, y)$，它给“预测值 $\hat{y}=f(x)$ 与真实值 $y$ 之间的差距”打分。训练就是在所有样本上把平均损失降到最低：

$$
\min_{f}\ \frac{1}{n}\sum_{i=1}^{n} L\big(f(x_i),\, y_i\big)
$$

- 对于预测连续数值的任务，常用**均方误差（MSE）**：$L(\hat{y}, y) = (\hat{y}-y)^2$。
- 对于预测类别的任务，常用**[交叉熵](../cross-entropy/)**等分类损失。

## 两大子类：回归与分类

监督学习按“输出 $y$ 的类型”分成两大家族：

- **回归（regression）**：$y$ 是**连续值**。例子：根据面积预测房价、根据历史销量预测明天的销量、预测气温。输出是一个实数。
- **分类（classification）**：$y$ 是**离散类别**。例子：判断邮件是否为垃圾邮件（是/否）、识别图片里是猫还是狗、判断一笔交易是否欺诈。输出是一个标签。

一句话区分：**问“多少”是回归，问“哪一类”是分类。**

## 一个具体例子

用 [Python](../python/) 的 `scikit-learn` 训练一个最简单的回归模型——根据面积预测房价：

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 输入 X：房子面积（平方米），每行是一个样本
X = np.array([[50], [60], [80], [100], [120]])
# 标签 y：对应的成交价（万元）—— 这就是“标准答案”
y = np.array([150, 175, 230, 280, 330])

model = LinearRegression()
model.fit(X, y)          # 学习 f: 面积 -> 价格

print(model.predict([[90]]))   # 预测一套 90 平米房子的价格
```

`fit` 这一步就是“对着标准答案做练习”：模型自动找出一条最贴合数据的直线，使预测价与真实价的均方误差最小。换成分类任务时，只需把 `LinearRegression` 换成 `LogisticRegression`，并让 `y` 变成类别标签（如 0/1）即可。

## 为什么重要（用在哪）

监督学习是[机器学习](../ml/)里**应用最广、最成熟**的一支。只要你能收集到“输入 + 正确答案”的成对数据，几乎都能套用它：信用评分、医学诊断、推荐系统、语音识别、机器翻译……它和另外两大范式形成对照：

- [无监督学习](../unsupervised-learning/)：数据**没有**标签，目标是发现隐藏结构（如[聚类](../clustering/)、降维）。
- [强化学习](../reinforcement-learning/)：没有现成答案，靠**与环境交互的奖励**来试错学习。

监督学习之所以好用，正是因为“答案明确”让训练目标非常清晰，评估也直接——拿没见过的样本看预测对不对就行。

## 在时间序列预测中的意义

这是本课最关键的一点：**时间序列预测本质上就是监督学习。** 表面上时间序列只是一串没有标签的数字，但我们可以用**滑动窗口（sliding window）** 把它“监督化”——人为构造出 $(X, y)$ 成对数据。

做法是：用过去连续 $k$ 个时刻的值作为特征 $X$，把紧接着的下一个值 $y_t$ 当作标签：

$$
X = [\,x_{t-k},\, \dots,\, x_{t-2},\, x_{t-1}\,] \quad\Longrightarrow\quad y = x_t
$$

举个具体的数值例子。假设原始序列是：

```
时刻:  1   2   3   4   5   6   7
值:   10  12  13  15  16  18  19
```

取窗口长度 $k = 3$，沿着时间往后滑，就能把这条序列变成一张**监督学习表格**：

| 特征 $x_{t-3}, x_{t-2}, x_{t-1}$ | 标签 $y = x_t$ |
| :--- | :--- |
| 10, 12, 13 | 15 |
| 12, 13, 15 | 16 |
| 13, 15, 16 | 18 |
| 15, 16, 18 | 19 |

有了这张表，预测问题就完全变成了我们前面讲的回归问题：学一个 $f$，输入三个历史值、输出下一个值。之后无论是线性回归、树模型还是[神经网络](../neural-network/)，都可以直接拿来训练。

**一个必须注意的细节：按时间切分。** 评估时不能像普通监督学习那样随机打乱再划分训练/测试集，因为那会让模型“偷看到未来”。正确做法是**按时间顺序切分**——用较早的数据训练，用较晚的数据测试，模拟“站在现在预测未来”的真实场景。

## 小结

- **监督学习** = 数据带标签，学习从输入 $x$ 到输出 $y$ 的映射 $f$，靠最小化**损失函数**来训练。
- 两大子类：**回归**（输出连续值，问“多少”）与**分类**（输出离散类别，问“哪一类”）。
- 与[无监督学习](../unsupervised-learning/)（无标签、找结构）和[强化学习](../reinforcement-learning/)（靠奖励试错）相对。
- **时间序列预测就是监督学习**：用**滑动窗口**把序列转成 $(X, y)$ 表格，用过去预测未来。
- 评估务必**按时间切分**，避免用未来数据训练导致的“偷看”。
