**正则化（regularization）** 指的是在模型训练时**加入额外的约束或惩罚**，限制模型的复杂度，从而抑制**过拟合**、提升**[泛化](../generalization/)**能力。一句话：让模型别太"任性"，学得简单一点、稳一点。

## 直观理解

回想过拟合的本质：模型为了完美拟合训练数据，把权重调得又大又怪，结果记住了一堆噪声。正则化的核心思想就是给模型**戴上一道紧箍咒**——

> **在拟合数据的同时，尽量让权重保持小、模型保持简单。**

这背后是**奥卡姆剃刀（Occam's razor）**：在解释能力相近时，越简单的模型越可能是对的，也越可能泛化得好。

打个比方：让你用一条曲线穿过一堆散点。

- 不加约束：你可以画一条剧烈扭动、穿过每一个点的曲线（权重巨大、过拟合）。
- 加了正则化：相当于有人在旁边提醒"曲线别拐那么狠"，于是你画出一条平滑、抓住整体趋势的曲线，反而对新点预测更准。

详见[过拟合](../overfitting/)。

## 数学表达

普通训练只最小化数据上的[损失](../loss-function/)。正则化则在目标函数里**额外加一个惩罚项**：

$$\min_{w}\;\; \underbrace{\frac{1}{n}\sum_{i=1}^{n} L\big(y_i, f(x_i)\big)}_{\text{拟合数据}} \;+\; \underbrace{\lambda\, \Omega(w)}_{\text{惩罚复杂度}}$$

- $\Omega(w)$ 是**复杂度惩罚项**，通常是权重的某种"大小"。权重越大，惩罚越重。
- $\lambda \ge 0$ 是**正则化强度（regularization strength）**，它控制两股力量的拔河：
  - $\lambda \to 0$：几乎不惩罚，回到普通拟合，容易**过拟合**。
  - $\lambda$ 很大：拼命压权重，模型变得过于简单，容易**欠拟合**。
  - 合适的 $\lambda$：在拟合和简单之间取得平衡。$\lambda$ 是一个需要用**验证集 / [交叉验证](../cross-validation/)**来调的超参数。

## 几种常见的正则化

不同的 $\Omega(w)$ 给出不同的正则化方式。

**L2 / 岭回归（Ridge）**：惩罚权重的平方和

$$\Omega(w) = \|w\|_2^2 = \sum_j w_j^2$$

L2 会让所有权重**整体变小、变平滑**，但一般不会把它们精确压到 0。它对付共线性、稳定模型特别有效，也常被称为**权重衰减（weight decay）**。

**L1 / Lasso**：惩罚权重的绝对值之和

$$\Omega(w) = \|w\|_1 = \sum_j |w_j|$$

L1 的神奇之处在于它会**把一部分权重精确压到 0**，从而自动做**特征选择（feature selection）**——不重要的特征直接被踢出模型，得到一个**稀疏（sparse）** 解。

为什么 L1 能"清零"而 L2 不能？看几何直觉。优化相当于在"惩罚预算"的约束区域内找损失最小的点：

- L2 的约束区域是一个**圆**（高维里是球），表面光滑，损失等高线碰到它时通常落在某个斜的位置，各分量都非零。
- L1 的约束区域是一个**菱形 / 钻石**（高维里是带尖角的多面体），它的**尖角正好落在坐标轴上**。损失等高线往外扩时，最容易先碰到这些尖角，而尖角处某些坐标恰好为 0 ——于是对应权重被压成 0。

**Elastic Net（弹性网）**：把 L1 和 L2 加在一起

$$\Omega(w) = \alpha\|w\|_1 + (1-\alpha)\|w\|_2^2$$

兼顾 L1 的稀疏性和 L2 的稳定性，在特征多且彼此相关时往往表现更好。

## 不止于惩罚项：其他正则化手段

广义的正则化，泛指一切"约束模型、防止它背噪声"的技巧：

- **[早停](../early-stopping/)（early stopping）**：盯着验证误差，一旦回升就停止训练，避免越练越过拟合。
- **[Dropout](../dropout/)**：训练[神经网络](../neural-network/)时随机"丢弃"一部分[神经元](../neuron/)，逼网络不依赖个别单元，学到更鲁棒的表示。
- **剪枝 / 限制深度（tree pruning / `max_depth`）**：对[决策树](../decision-tree/)限制最大深度或剪掉无用枝叶，防止树长到把每个样本都背下来。
- **数据增强（data augmentation）**：对数据做合理变换（旋转、加噪声等）人为扩充训练集，相当于告诉模型"这些变化无关紧要"。
- **权重衰减（weight decay）**：训练时让权重持续缩小，本质上等价于 L2 正则。

## 一个具体例子（sklearn）

下面用 Ridge 和 Lasso 直观看看：**增大 $\alpha$（即 $\lambda$）会把系数往小里压**。

```python
import numpy as np
from sklearn.linear_model import Ridge, Lasso

rng = np.random.RandomState(0)
X = rng.randn(100, 5)
# 真实关系只依赖前两个特征，后三个是噪声
y = 3 * X[:, 0] - 2 * X[:, 1] + 0.1 * rng.randn(100)

for alpha in [0.0, 0.1, 1.0, 10.0]:
    ridge = Ridge(alpha=alpha).fit(X, y)
    print(f"Ridge alpha={alpha:>4}: {np.round(ridge.coef_, 2)}")

for alpha in [0.001, 0.05, 0.2, 1.0]:
    lasso = Lasso(alpha=alpha).fit(X, y)
    print(f"Lasso alpha={alpha:>5}: {np.round(lasso.coef_, 2)}")
```

你会观察到：

- **Ridge**：随着 `alpha` 增大，所有系数**整体收缩**变小，但很少恰好为 0。
- **Lasso**：随着 `alpha` 增大，那些**没用的特征系数一个个变成 0**，最后只留下真正重要的前两个——这就是自动特征选择。

## 为什么重要：连接过拟合与偏差—方差

正则化是对抗[过拟合](../overfitting/)最直接、最常用的武器。用[偏差—方差权衡](../bias-variance/)的语言说：

> **正则化主动引入一点点偏差，来换取方差的大幅下降。**

- 不加正则：模型方差高，对训练数据里的噪声过度敏感（过拟合）。
- 加了正则：模型变简单、变稳，方差降下来，虽然偏差略升，但**总的泛化误差更小**。

所以调 $\lambda$ 的过程，本质上就是在偏差和方差之间找那个让泛化误差最低的甜点。详见[泛化](../generalization/)。

## 在时间序列预测中的意义

时间序列预测里，我们常常构造大量**滞后特征（lag features）**：用 $t-1, t-2, \dots, t-k$ 时刻的值来预测 $t$。这会带来两个麻烦——

- **特征又多又相关**：相邻滞后高度共线，[线性模型](../linear-model/)很容易过拟合，把历史里的偶然波动当成规律。
- **噪声丰富**：真实时间序列噪声大，不加约束的模型很容易去拟合噪声而非趋势。

正则化在这里特别有用：

- **L2 / Ridge** 稳定系数，缓解滞后特征间的共线性，让预测更平滑。
- **L1 / Lasso** 自动**挑出哪些滞后真正重要**——比如它可能告诉你只有 $t-1$ 和 $t-7$（昨天和上周同一天）有用，其余滞后系数清零，模型更简洁、更可解释，也更不容易过拟合。

一句话：在滞后特征多、噪声大的时间序列里，正则化帮你**只学规律、不背噪声**。

## 小结

- **正则化**通过加入约束/惩罚来限制模型复杂度，目的是抑制**过拟合**、提升**泛化**。
- 核心目标函数：$\min_w \frac1n\sum L + \lambda\,\Omega(w)$；**$\lambda$ 越大越简单**，需用验证集调。
- **L2/Ridge** 平滑收缩权重；**L1/Lasso** 产生稀疏、做特征选择（菱形约束的尖角落在坐标轴上）；**Elastic Net** 兼顾两者。
- 广义正则化还包括**早停、Dropout、剪枝/限深、数据增强、权重衰减**。
- 从偏差—方差看：正则化**用一点偏差换大量方差下降**。
- 时间序列里用正则化驯服众多**滞后特征**、防止拟合噪声，**L1** 还能帮你挑出关键的滞后。
