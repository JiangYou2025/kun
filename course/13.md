## 13.1 没有“最好的模型”

前面十二讲攒了一整箱工具——线性、ARIMA、ETS、LSTM、Transformer、KUN。新手最常见的困惑是"那我到底该用哪个"。答案是：**取决于任务和数据，而不是取决于模型有多新**。这一讲不再介绍新模型，而是教你怎么**根据问题选工具**。

## 13.2 先分清你在做什么任务

"时间序列"底下其实有好几种不同的任务，模型选择从这里开始分叉：

| 任务 | 要做什么 | 常用方法 |
|------|---------|---------|
| **预测 (forecasting)** | 给定过去，推断未来若干步 | ARIMA / ETS / 深度模型 / KUN |
| **异常检测** | 找出不正常的时刻 | 预测残差阈值、孤立森林、重构误差 |
| **分类** | 判断整段序列属于哪类 | LSTM / TCN / Transformer、特征 + GBDT |
| **插补** | 填补缺失时刻 | 插值、状态空间模型、深度插补 |

本课程主线是**预测**，但选模型前先确认任务类型——异常检测和分类的评价标准、模型结构都不一样。

## 13.3 把预测问题“表格化”：特征 + GBDT

在经典模型和深度学习之间，还有一条非常实用的中间路线：**用滑动窗口把序列变成表格，再上梯度提升树**。

```
[x₁ … x₅] → x₆      （用过去 5 步当特征，预测下一步）
[x₂ … x₆] → x₇
```

除了原始滞后值，还能造一堆好用的特征：

| 特征类型 | 例子 |
|---------|------|
| 滞后值 | $x_{t-1}, x_{t-7}, x_{t-30}$ |
| 滚动统计 | 7 日均值、30 日标准差 |
| 时间特征 | 星期几、月份、是否节假日 |
| 差分特征 | $x_t - x_{t-1}$、$x_t - x_{t-7}$ |

**LightGBM / XGBoost** 在这种表格上是王者：不用归一化、自动抓非线性、训练快、还能看特征重要性。零售、需求预测这类"有丰富日历 / 促销特征"的场景，它常常是性价比最高的选择。

> 注意：表格化之后它**仍然是时间序列**——交叉验证要用 `TimeSeriesSplit`（按时间向前滚动），绝不能随机 K 折，否则数据泄漏（第 2 讲）。

## 13.4 选模型的几条主线

把"数据特点"映射到"模型族"：

| 数据 / 约束 | 推荐起点 |
|------------|---------|
| 单变量、短序列、要可解释 | ARIMA / ETS（第 8、12 讲）|
| 有丰富日历 / 促销特征 | GBDT（本讲）|
| 中等长度、端到端 | LSTM / GRU / TCN（第 9 讲）|
| 长序列、多变量、数据量大 | Transformer / PatchTST（第 10 讲）|
| 多尺度、要又快又准 | KUN（第 11 讲）|
| 金融 / 重尾 / 跨数量级 | 先 log 变换再选模型（第 12 讲）|

## 13.5 一条务实的工作流

```
1. 想清任务      → 预测？检测？分类？预测多远？
2. 看数据        → 多长、几变量、什么频率、有无重尾（第 2、4 讲）
3. 跑基线        → 朴素法 / 季节朴素 / 线性，定下限（第 3 讲）
4. 顺阶梯往上加  → ARIMA/ETS → GBDT → 深度模型，每步都和基线比
5. 诚实评估      → 按时间回测、多指标、看残差（第 4 讲）
6. 够用即止      → 提升不明显就别再加复杂度
```

## 13.6 选择的黄金法则

- **先简单后复杂**：永远从基线和线性起步，复杂模型必须证明自己更好。
- **复杂度要配数据量**：数据少用经典模型，数据多深度模型才发挥得出。
- **可解释性是约束之一**：很多业务场景宁要"能解释的 ARIMA"，也不要"黑箱里高 1%"。
- **算力和维护成本也算账**：上线后要重训、要监控漂移，简单模型往往更省心。

> 一句话：**模型选择不是选最强的，而是选最匹配"任务 + 数据 + 约束"的那个。**
