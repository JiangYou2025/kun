## 5.1 为什么要“拆开”一条序列

一条真实序列往往是好几股力量叠在一起：长期在涨、每年夏天冲高、偶尔来个突发事件。如果直接拿原始序列建模，模型得同时对付所有这些模式，既难学也难解释。**分解 (decomposition)** 的动机就是"分而治之"——先把序列拆成几种结构清晰的成分，分别理解、分别处理，再合起来。它既是**理解数据**的工具，也是**建模前的预处理**。

## 5.2 四种基本成分

我们通常把一条序列看成这几种成分的叠加：

- **趋势 (Trend) $T_t$**：长期上升或下降的方向。
- **季节性 (Seasonality) $S_t$**：固定周期的重复模式（每周、每年）。
- **周期 (Cycle)**：周期不固定的波动（如经济周期），常并入趋势一起处理。
- **噪声 / 残差 (Noise) $R_t$**：随机、无法预测的部分。

直觉例子：月度冰淇淋销量随城市扩张缓慢上升（**趋势**），每年夏天冲高、冬天回落（**季节**），一次突发热浪带来额外销量（接近**噪声**）。分解就是把这三股力量拆开。

## 5.3 加法分解与乘法分解

$$x_t = T_t + S_t + R_t \quad\text{(加法)} \qquad\qquad x_t = T_t \times S_t \times R_t \quad\text{(乘法)}$$

怎么选？看**季节波动的幅度**：

- **加法**：季节振幅恒定，不随趋势变大 → 用加法。
- **乘法**：值越大、季节波动越大（典型如销量、价格）→ 用乘法。

乘法型可以**先取对数变成加法**：$\log x_t = \log T_t + \log S_t + \log R_t$。这正是第 12 讲要专门讲的 log 变换的用武之地。

## 5.4 怎么分解：移动平均与 STL

- **移动平均分解**：用窗口均值平滑出趋势，从去趋势后的序列里按周期取平均得到季节成分，剩下的就是残差。思路朴素、易懂。
- **STL (Seasonal-Trend decomposition using LOESS)**：更灵活，**允许季节成分随时间缓慢变化**，对异常更稳健，是实务中的主力工具。

```python
from statsmodels.tsa.seasonal import STL
stl = STL(series, period=12)   # period 一定要设对
result = stl.fit()
result.plot()                  # 趋势 / 季节 / 残差 三张图
```

## 5.5 去趋势与去季节：为下一讲铺路

为什么分解这么重要？因为**很多经典模型要求输入是平稳的**（没有趋势和季节，下一讲会严格定义）。分解给了我们去掉它们的手段：

- 去趋势 → 差分或回归减掉 $T_t$；
- 去季节 → 季节性差分或减掉 $S_t$；
- 剩下的"去趋去季残差"才是模型真正要学的东西。

## 5.6 实践要点

- **period 设错全盘皆输**：STL 等方法对周期长度极其敏感，把日数据的周周期 7 设成 30，分出来的成分会完全误导你。先用第 4 讲的季节子图 / 第 7 讲的自相关确认周期。
- **分解不是目的**：它是为了让后面建模更容易；别为分解而分解。
- **记得能合回去**：分出的成分最终要能加 / 乘回原序列，预测时也要把各成分的预测合起来。
