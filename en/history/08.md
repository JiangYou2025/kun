In the 2000s, a flood of forecasting problems with covariates (demand, clicks, energy consumption) appeared, while general-purpose machine learning methods — support vector machines, random forests, gradient boosting — matured. At the same time, large-scale forecasting competitions such as M3 (2000) pitted all kinds of methods against each other publicly on common data, and reached a counter-intuitive yet far-reaching conclusion: **complex methods do not necessarily beat simple ones**.

## Key contribution 1: support vector regression (SVR)

Robust regression with nonlinear, high-dimensional features.

Use the $$\varepsilon$$-insensitive loss + maximum margin + the kernel trick:

$$ \min_{w,b}\ \tfrac12\lVert w\rVert^2 + C\sum_i(\xi_i+\xi_i^{*})\quad \text{s.t. } \lvert y_i-(w^\top\phi(x_i)+b)\rvert \le \varepsilon+\xi $$

The kernel function implicitly defines an inner product of high-dimensional features: $$K(x,x')=\phi(x)^\top\phi(x')$$.

Errors inside the $$\varepsilon$$-tube are not penalised; only points outside $$\varepsilon$$ pay a cost $$\xi$$ — which yields **sparsity** (only a few "support vectors" determine the model). $$\tfrac12\lVert w\rVert^2$$ controls complexity, and $$C$$ trades off fit against smoothness. The kernel trick lets the model fit nonlinearity without explicitly lifting to higher dimensions.

## Key contribution 2: gradient boosting (Friedman, 2001)

How can a collection of "weak learners" gradually approximate a complex nonlinear target with many features (lags, rolling statistics, calendar)?

Forward stagewise additive modelling: at each step, add a new tree that fits the **negative gradient** of the current loss (for squared loss, the residuals):

$$ F_m(x) = F_{m-1}(x) + \nu\, h_m(x),\qquad h_m \approx -\left[\frac{\partial L(y,F)}{\partial F}\right]_{F=F_{m-1}} $$

This generalises "fitting the residuals" to "taking one step in the direction of the loss's negative gradient" — exactly gradient descent in function space. The learning rate (shrinkage factor) $$\nu\in(0,1]$$ makes each step a small one, markedly curbing overfitting; using decision trees as $$h_m$$ naturally handles interactions and nonlinearity among features.

This decade also established the standard recipe of **turning time series into supervised learning**: build lag features, rolling means/variances, calendar features (day of week, holidays) and Fourier terms (seasonality), then hand them to GBDT/SVR.

For tabular forecasting with rich covariates, GBDT became the long-reigning champion (an advantage that carried over to later XGBoost/LightGBM). The evidence from the M competitions also pushed the field to take the power of "simple methods + good features" seriously, and foreshadowed **global models** (one model learning many series at once).

The machine learning era shifted the focus of forecasting from "carefully specifying a model structure for each individual series" to "feature construction + general-purpose learners", and used a competition culture to drive objective, reproducible method comparison — both of which directly shaped the deep learning practice that followed.
