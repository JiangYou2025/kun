## 12.1 有些数据“不一样”

不是所有序列都长得规规矩矩。金融收益、股价、社交媒体的转发量、网站访问量这类数据，常常有几个共同的"脾气"：

- **跨数量级**：今天 100，明天可能 100 万——值的大小横跨好几个量级。
- **重尾 / 极端事件**：偶尔来一个暴涨暴跌，远超平时波动。
- **方差随水平变化**：值越大，绝对波动越大（乘法型，见第 5、6 讲）。

直接对这种数据建模，少数极端值会主导一切。这一讲讲两件配套的事：用 **log 变换**驯服它们，用**指数平滑**这条经典路线快速预测。

## 12.2 log 变换：为什么、怎么用

对这类数据，最常用的第一步就是取对数：

$$y_t = \log x_t \quad(\text{或 } \log(1+x_t)\ \text{以容纳 } x_t = 0).$$

它做了三件好事:

1. **压缩量级**：把跨数量级的值拉到同一尺度，极端值不再一手遮天。
2. **稳定方差**：把"乘法型波动"变成"加法型"——回顾第 5 讲，$\log(T_t S_t R_t) = \log T_t + \log S_t + \log R_t$。
3. **让"比例变化"线性化**：log 差分 $\log x_t - \log x_{t-1}$ 近似**收益率 / 增长率**，这正是金融最关心的量。

> **金融里的标准操作**：几乎不直接预测价格 $x_t$，而是预测**对数收益** $r_t = \log x_t - \log x_{t-1}$——它更接近平稳，量纲统一，还能直接对应风险度量。Twitter / 访问量这类计数数据则常用 $\log(1+x)$。

## 12.3 别忘了反变换

在 log 空间里建模、预测，最后必须 $\hat{x}_t = \exp(\hat{y}_t)$ 变回原始尺度才能用。注意：$\exp$ 是非线性的，"log 空间的均值"反变换后并不等于"原始空间的均值"，做无偏点预测时需要加一个方差修正项。Box-Cox（第 6 讲）是 log 的推广，$\lambda \to 0$ 时就退化为 log。

## 12.4 指数平滑：另一条经典主线

讲完变换，转向一族特别适合这类业务数据的经典模型——**指数平滑**。它的核心直觉是：**越近的观测越重要，权重随时间指数衰减**。最简单的 **简单指数平滑 (SES)**：

$$\hat{x}_{t+1} = \alpha x_t + (1-\alpha)\hat{x}_t, \qquad \alpha \in (0,1).$$

$\alpha$ 越大越重视最近值，越小越平滑。把它递归展开，就会看到它其实是对全部历史的指数加权平均。SES 适合**无趋势、无季节**的序列，等价于 ARIMA(0,1,1)。

## 12.5 Holt 与 Holt-Winters：加上趋势和季节

- **Holt 线性趋势法**：在 SES 上加一个趋势项，用两条递推方程分别更新水平 $\ell_t$ 和趋势 $b_t$，预测 $\hat{x}_{t+h} = \ell_t + h\,b_t$。
- **Holt-Winters**：再加季节项 $s_t$，得到完整模型。

$$\text{加法：}\ \hat{x}_{t+h} = \ell_t + h b_t + s_{t-m+h}, \qquad \text{乘法：}\ \hat{x}_{t+h} = (\ell_t + h b_t)\times s_{t-m+h}.$$

**乘法版**正好对应"季节波动随水平放大"的数据——和 12.2 的 log 思路是一体两面（先 log 再用加法版，往往等价于直接用乘法版）。

## 12.6 ETS 框架

ETS = **E**rror + **T**rend + **S**easonal，系统地组合三种成分的加法 / 乘法 / 阻尼变体：

| 成分 | 选项 |
|------|------|
| Error | A（加法）/ M（乘法）|
| Trend | N（无）/ A（加法）/ Ad（阻尼）|
| Seasonal | N（无）/ A（加法）/ M（乘法）|

`statsforecast` / `statsmodels` 能按 AIC 自动挑最优组合。**阻尼趋势 (damped)** 用一个 $0<\phi<1$ 让趋势随步长逐渐变平，避免长程外推"飞出去"，常是稳健的默认选择。

## 12.7 实践要点

- **先变换再建模**：金融 / 计数数据先 log（或 Box-Cox）稳住方差，再上 ARIMA / ETS / 深度模型。
- **指数平滑 vs ARIMA**：思路不同（加权平均 vs 线性组合值与误差），但很多 ETS 有等价 ARIMA 形式。实战两种都试，取好的。
- **极端事件单独处理**：log 能压缩但消不掉黑天鹅；风险场景要结合第 14 讲的概率预测看尾部。
