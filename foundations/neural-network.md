**神经网络（Neural Network）** 是由大量简单计算单元——[神经元](../neuron/)——分层连接而成的数学模型。它通过[前向传播](../forward-propagation/)计算输出，再通过[反向传播](../backpropagation/)从错误中学习参数，从而把"输入"映射成我们想要的"输出"。

## 直观理解

想象一条流水线。原料（输入数据，比如过去 96 个时刻的气温）从一端进入，经过一层又一层的"加工车间"，最后一端输出成品（比如未来 24 个时刻的气温预测）。

每个车间里有很多工人（神经元）。每个工人做的事都极其简单：

1. 把上一层传来的若干数字各自乘以一个"重视程度"（权重 $w$）；
2. 全部加起来，再加一个偏置 $b$；
3. 把结果通过一个非线性的"开关"（[激活函数](../activation-function/)）。

单个工人很笨，但成千上万个工人分层协作，整体却能拟合极其复杂的规律。**神经网络的威力不来自单个神经元，而来自分层组合与海量参数。**

## 数学表达

一个神经元的计算是一次"加权求和 + 激活"：

$$
a = \sigma\!\left( \sum_{i=1}^{n} w_i x_i + b \right)
$$

- $x_i$：输入的第 $i$ 个分量（上一层的输出）；
- $w_i$：对应的权重，表示这个输入有多重要，是要学习的参数；
- $b$：偏置，给神经元一个可调的基准线；
- $\sum_{i=1}^{n} w_i x_i + b$：加权求和，是一个线性运算；
- $\sigma(\cdot)$：激活函数（如 ReLU、Sigmoid），引入非线性；
- $a$：该神经元的输出（activation）。

把整层神经元一起写成矩阵形式更紧凑：

$$
\mathbf{h}^{(l)} = \sigma\!\left( \mathbf{W}^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)} \right)
$$

- $\mathbf{h}^{(l-1)}$：第 $l-1$ 层的输出向量（第一层就是输入 $\mathbf{x}$）；
- $\mathbf{W}^{(l)}$：第 $l$ 层的权重矩阵，每一行对应该层的一个神经元；
- $\mathbf{b}^{(l)}$：第 $l$ 层的偏置向量；
- $\mathbf{h}^{(l)}$：第 $l$ 层的输出。

整个网络就是把这个式子从第 1 层一直套到第 $L$ 层：输入进、输出出，这一路就是**前向传播**。

### 为什么必须有激活函数

如果去掉 $\sigma$，那么多层叠加 $\mathbf{W}^{(3)}(\mathbf{W}^{(2)}(\mathbf{W}^{(1)}\mathbf{x}))$ 仍然只是一次线性变换 $\mathbf{W}'\mathbf{x}$——再多层也等价于一层，无法表达曲线、拐点、阈值这些非线性关系。**激活函数是神经网络能"深"且"强"的关键。**

## 它如何学习

网络刚初始化时权重是随机的，输出基本是乱猜。学习分三步循环：

1. **前向传播**：用当前参数算出预测 $\hat{y}$；
2. **算损失**：用损失函数衡量预测和真实值 $y$ 的差距，比如均方误差
   $$ \mathcal{L} = \frac{1}{N}\sum_{j=1}^{N}\left(\hat{y}_j - y_j\right)^2 $$
   其中 $N$ 是样本数，$\hat{y}_j$ 是预测，$y_j$ 是真实值；
3. **[反向传播](../backpropagation/) + [优化器](../optimizer/)**：用链式法则算出损失对每个参数的梯度 $\frac{\partial \mathcal{L}}{\partial w}$，再沿梯度反方向微调参数：
   $$ w \leftarrow w - \eta \,\frac{\partial \mathcal{L}}{\partial w} $$
   $\eta$ 是学习率，控制每步走多大。

把这三步在大量数据上重复成千上万次，参数就逐渐收敛到能给出好预测的值。

## 一个具体例子

用 PyTorch 风格搭一个 3 层网络，把 96 步历史映射到 24 步预测：

```python
import torch.nn as nn

net = nn.Sequential(
    nn.Linear(96, 128),   # 第 1 层：96 维 -> 128 维
    nn.ReLU(),            # 激活
    nn.Linear(128, 64),   # 第 2 层：128 -> 64
    nn.ReLU(),
    nn.Linear(64, 24),    # 输出层：64 -> 24 步预测
)

x = torch.randn(32, 96)  # 一批 32 条样本，每条 96 步历史
y_hat = net(x)           # 形状 (32, 24)
```

这短短几行就是一个完整可训练的神经网络：三个 `Linear` 是权重矩阵，`ReLU` 是激活函数，`net(x)` 内部做的正是上面那串矩阵乘法。

## 在时间序列预测中的意义

时间序列预测的本质，就是学习一个函数 $f$：把历史窗口 $[x_{t-95}, \dots, x_t]$ 映射到未来 $[x_{t+1}, \dots, x_{t+24}]$。神经网络正好擅长**从数据中自动学这种复杂映射**，无需手工设定模型形式。

不同任务催生了不同结构（它们都是神经网络）：处理局部模式用 [CNN](../cnn/)，处理顺序依赖用 [RNN](../rnn/) / [LSTM](../lstm/)，捕捉长程关系用 [注意力](../attention/) 与 [Transformer](../transformer/)，而本站主推的多尺度预测模型 **Kernel U-Net (KUN)** 则建立在 [U-Net](../u-net/) 结构之上。理解通用的神经网络框架，是看懂这些专用架构的前提。

## 小结

- 神经网络 = 大量神经元分层连接，靠**权重**与**偏置**参数化。
- **前向传播**算输出，**反向传播 + 优化器**更新参数。
- **激活函数**带来非线性，是"深度"有意义的根本。
- 同一套框架可以裁剪出 MLP、CNN、Transformer、U-Net 等不同架构。
