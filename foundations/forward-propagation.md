**前向传播（forward propagation）**指的是：把输入数据从网络的第一层一路"喂"到最后一层，逐层做"加权求和 + 激活"，最终算出预测结果的过程。它是神经网络"做预测"的那一半（另一半是[反向传播](../backpropagation/)负责"学习"）。

## 直观理解

把神经网络想象成一条**流水线**。原料（输入特征）从入口进来，每经过一个工位（一层），都会被加工一次：先按一定配方混合（线性加权求和），再过一道"质检阀门"（[激活函数](../activation-function/)）决定让多少信号通过。原料一路向前流动，绝不回头，最后从出口出来的成品就是网络的**预测值**。

"前向"这个词强调的就是这个**单向流动**：数据只朝输出方向走。等到我们要根据误差去调整网络时，信息才会反着传回来——那就是反向传播。

## 数学表达

设网络有 $L$ 层。记第 $l$ 层的输入向量为 $a^{(l-1)}$（也就是上一层的输出），该层有权重矩阵 $W^{(l)}$ 和偏置向量 $b^{(l)}$。那么这一层做两件事：

$$
z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}
$$

$$
a^{(l)} = \sigma\big(z^{(l)}\big)
$$

逐个符号解释：

- $a^{(l-1)}$：第 $l-1$ 层的**激活输出**（第 0 层就是原始输入 $x$，即 $a^{(0)} = x$）。
- $W^{(l)}$：第 $l$ 层的**权重矩阵**，形状是 $(\text{本层神经元数} \times \text{上层神经元数})$。
- $b^{(l)}$：第 $l$ 层的**偏置**，给每个神经元一个可调的基准值。
- $z^{(l)}$：**加权和**（也叫 pre-activation，激活前的值）。
- $\sigma(\cdot)$：**激活函数**，例如 ReLU、Sigmoid（逐元素作用）。
- $a^{(l)}$：本层的输出，又会成为下一层的输入。

把这两步从 $l=1$ 一直算到 $l=L$，最后的 $a^{(L)} = \hat{y}$ 就是网络的预测。整条链路可以写成嵌套函数：

$$
\hat{y} = \sigma^{(L)}\Big(W^{(L)} \, \sigma^{(L-1)}\big(\cdots \sigma^{(1)}(W^{(1)} x + b^{(1)}) \cdots\big) + b^{(L)}\Big)
$$

## 一个具体例子

假设一个最小网络：输入 2 维，隐藏层 2 个神经元用 ReLU，输出层 1 个神经元（线性）。给定

$$
x = \begin{bmatrix} 1 \\ 2 \end{bmatrix},\quad
W^{(1)} = \begin{bmatrix} 0.5 & -0.5 \\ 1.0 & 0.0 \end{bmatrix},\quad
b^{(1)} = \begin{bmatrix} 0 \\ -1 \end{bmatrix}
$$

第一步算加权和：

$$
z^{(1)} = \begin{bmatrix} 0.5\cdot1 + (-0.5)\cdot2 \\ 1.0\cdot1 + 0\cdot2 \end{bmatrix} + \begin{bmatrix} 0 \\ -1 \end{bmatrix}
= \begin{bmatrix} -0.5 \\ 1.0 \end{bmatrix} + \begin{bmatrix} 0 \\ -1 \end{bmatrix}
= \begin{bmatrix} -0.5 \\ 0 \end{bmatrix}
$$

过 ReLU（负数清零）：

$$
a^{(1)} = \mathrm{ReLU}(z^{(1)}) = \begin{bmatrix} 0 \\ 0 \end{bmatrix}
$$

哎呀——两个隐藏神经元都被"关掉"了。这就提醒我们：ReLU 会让一部分神经元在某些输入下输出 0。最后输出层（设 $W^{(2)} = [1, 1],\, b^{(2)} = 0.3$）：

$$
\hat{y} = 1\cdot0 + 1\cdot0 + 0.3 = 0.3
$$

用代码验证：

```python
import numpy as np

x  = np.array([1.0, 2.0])
W1 = np.array([[0.5, -0.5], [1.0, 0.0]])
b1 = np.array([0.0, -1.0])
W2 = np.array([1.0, 1.0])
b2 = 0.3

z1 = W1 @ x + b1          # [-0.5, 1.0] -> +b1 -> [-0.5, 0.0]
a1 = np.maximum(0, z1)    # ReLU -> [0, 0]
y  = W2 @ a1 + b2         # 0.3
print(z1, a1, y)          # [-0.5  0. ] [0. 0.] 0.3
```

## 为什么重要 / 用在哪

- **它是推理（inference）的全部**。模型部署上线后做预测，跑的就是前向传播——又快又简单。
- **它是训练的前半程**。每次训练都要先前向跑一遍得到 $\hat{y}$，再算损失 $\mathcal{L}(\hat{y}, y)$，然后才能反向传播求梯度。
- 前向传播中保存的中间值 $z^{(l)}, a^{(l)}$ 会被[反向传播](../backpropagation/)复用，这正是[自动微分](../autodiff/)框架（PyTorch/TensorFlow）自动帮你管理"计算图"的原因。

## 在时间序列预测中的意义

对像 [RNN](../rnn/)、[LSTM](../lstm/) 这样的序列模型，前向传播是沿着**时间步**展开的：第 $t$ 步的隐藏状态依赖第 $t-1$ 步，信息一步步向前流。本站的旗舰模型 [Kernel U-Net (KUN)](../../zh/kun/) 则是多尺度结构，前向传播会把长回看窗口逐级下采样、再逐级上采样还原——但本质仍是"输入逐层变换得到预测"这一套。理解前向传播，是看懂任何预测模型如何工作的第一步。

## 小结

- 前向传播 = **数据单向地从输入流到输出**，逐层"线性变换 + 激活"。
- 核心公式：$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$，$a^{(l)} = \sigma(z^{(l)})$。
- 它既是**预测**本身，也是**训练循环的第一步**；中间值会留给反向传播用。
