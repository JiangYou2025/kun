## 3.1 Pourquoi commencer par les modèles linéaires

La prévision peut sembler mystérieuse, mais l'idée la plus naïve tient en une phrase : **l'avenir est une certaine combinaison linéaire du passé**. Les modèles linéaires sont simples, calculables à la main, interprétables, et — c'est le point le plus souvent sous-estimé — **sur de nombreux benchmarks réels, une seule couche linéaire égale, voire bat, des modèles profonds bien plus complexes** (les leçons 10 et 11 reviendront sur ce fait étonnant). Nous en faisons donc le point de départ de tout, et la « référence à battre absolument ».

Cette leçon n'utilise que des exemples et les formules les plus élémentaires pour vous faire parcourir le fil conducteur « ajuster → prévoir → examiner le résultat ».

## 3.2 Ajuster la tendance avec une droite

Le modèle le plus simple : on suppose que la valeur croît linéairement avec le temps. En prenant le temps $t$ comme variable explicative,

$$\hat{x}_t = a + b\,t.$$

$a$ est l'ordonnée à l'origine (le point de départ), $b$ la pente (de combien la valeur augmente à chaque pas). **Ajuster (fitting)**, c'est trouver dans les données historiques les valeurs de $a, b$ les plus appropriées ; **prévoir (forecasting)**, c'est substituer les instants $t$ futurs dans cette droite.

Exemple : les ventes journalières d'un magasin augmentent d'environ 2 articles par jour à partir de 100 articles ; alors $\hat{x}_t = 100 + 2t$, et la prévision pour le 30e jour est $100 + 2\times 30 = 160$ articles.

## 3.3 Comment calculer le « plus approprié » : les moindres carrés

Qu'est-ce que « la droite la plus appropriée » ? Nous voulons que **l'erreur totale entre la prévision et la valeur réelle soit minimale**. En la mesurant par l'erreur quadratique :

$$\min_{a,b}\ \sum_{t=1}^{T} \big(x_t - (a + b\,t)\big)^2.$$

Ce sont les **moindres carrés (least squares)**. Ils admettent une solution analytique (on applique directement la formule, sans itération) :

$$b = \frac{\sum_t (t-\bar{t})(x_t-\bar{x})}{\sum_t (t-\bar{t})^2}, \qquad a = \bar{x} - b\,\bar{t}.$$

où $\bar t, \bar x$ sont les moyennes du temps et des valeurs. **Cette démarche « définir une perte → la minimiser » est l'ossature commune de tous les modèles qui suivent (y compris les réseaux de neurones)** ; seuls le modèle se complexifie et la résolution passe à la descente de gradient.

## 3.4 Prédire l'avenir à partir du passé : le point de vue autorégressif

Prendre directement le temps $t$ comme variable explicative est trop grossier : cela suppose une croissance toujours uniforme. Une idée plus adaptée aux séries temporelles consiste à **utiliser les valeurs des quelques pas précédents pour prédire le pas suivant**. C'est l'**autorégression (AutoRegression, AR)** :

$$\hat{x}_t = c + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p}.$$

C'est toujours un modèle linéaire — simplement, la variable explicative n'est plus « le temps » mais « les observations passées ». Les coefficients $\phi_i$ s'obtiennent eux aussi par les moindres carrés. Intuitivement : un $\phi_1$ élevé signifie qu'« hier et aujourd'hui sont fortement corrélés », la série a une grande inertie. La leçon 8 l'étendra au modèle ARIMA complet.

## 3.5 Prévision à un pas et prévision multi-pas

Le modèle ne prédit que le pas suivant ; comment faire pour prévoir les 10 prochains pas ? Deux approches :

- **Récursive (recursive)** : on prédit $\hat{x}_{t}$, on le traite comme une vraie valeur pour prédire $\hat{x}_{t+1}$, et ainsi de suite. Simple, mais les erreurs s'accumulent.
- **Directe (direct)** : on entraîne un modèle distinct pour chaque horizon, qui prédit respectivement le 1er pas, le 2e pas… Plus stable, mais il faut entraîner plusieurs modèles.

Il est important de saisir cette différence : **être précis à un pas ne garantit pas d'être précis à plusieurs pas**, et plus on prédit loin, plus l'incertitude est grande.

## 3.6 Le processus complet : un exemple minimal

En assemblant ce qui précède, on obtient une prévision complète :

1. **Découper les données** (leçon 2) : utiliser $x_1\ldots x_{t_1}$ comme ensemble d'entraînement.
2. **Ajuster** : obtenir $a,b$ (ou les $\phi$ de l'AR) par les moindres carrés sur l'ensemble d'entraînement.
3. **Prévoir** : calculer $\hat{x}_t$ pour les instants / l'historique de la portion de test.
4. **Examiner le résultat** (leçon 4) : tracer la prévision et la réalité ensemble, calculer l'erreur.

```python
import numpy as np
t = np.arange(len(train))
b, a = np.polyfit(t, train, deg=1)        # ajustement d'une droite par moindres carrés
future = np.arange(len(train), len(train)+H)
pred = a + b * future                      # extrapolation sur les H prochains pas
```

## 3.7 Les limites des modèles linéaires

Les modèles linéaires misent sur une « simplicité honnête », mais il faut savoir ce qu'ils ne peuvent pas apprendre :

- **Non-linéarité** : seuils, saturations, ruptures leur échappent.
- **Saisonnalité multiplicative** : quand l'amplitude grandit avec le niveau, il faut d'abord appliquer une transformation log (leçon 12).
- **Couplage multivarié** : les interactions complexes entre variables relèvent des modèles d'apprentissage automatique et d'apprentissage profond vus plus loin.

Mais retenez bien ceci : **tout modèle complexe doit d'abord prouver qu'il fait mieux que cette droite**, sinon sa complexité ne sert à rien.
