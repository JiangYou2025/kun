**评估指标（Evaluation Metrics）** 是衡量模型好坏的**量化标准**。指标必须**匹配业务目标**，并且应当在模型从未见过的**测试集**上报告。

## 直观理解

**指标就是你"打分用的那把尺子"——选错尺子，再好的模型也会被你误判。**

同一个模型，用不同指标看，结论可能完全相反。比如一个预测销量的模型，平均误差看起来不大，但它在几个大促日上错得离谱；如果你的业务最怕"大促备货失误"，那"平均误差小"这个好成绩就毫无意义。

所以学评估指标，重点不只是记公式，而是理解**每把尺子在量什么、对什么敏感、什么时候会骗人**，然后**根据业务目标挑对那把尺子**。

## 回归指标

回归任务预测的是**连续数值**（如气温、销量、股价）。设真实值为 $y_i$、预测值为 $\hat y_i$、样本数为 $n$。

**平均绝对误差 MAE（Mean Absolute Error）**

$$\text{MAE} = \frac{1}{n}\sum_{i=1}^{n}\left|y_i-\hat y_i\right|$$

误差的平均绝对大小，单位和 $y$ 一样，直观、对**异常值不敏感**。

**均方误差 MSE（Mean Squared Error）**

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2$$

先平方再平均，会**重罚大误差**；但单位是 $y$ 的平方，不好解读。

**均方根误差 RMSE（Root Mean Squared Error）**

$$\text{RMSE} = \sqrt{\text{MSE}}$$

开根号后**单位与 $y$ 相同**，既保留了"重罚大误差"的特性，又便于解读，是最常用的回归指标之一。

**决定系数 $R^2$**

$$R^2 = 1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}$$

表示模型比"只用均值预测"好多少。$R^2=1$ 完美，$R^2=0$ 等于瞎猜均值，**可以为负**（比均值还差）。

**平均绝对百分比误差 MAPE**

$$\text{MAPE} = \frac{1}{n}\sum_{i=1}^{n}\left|\frac{y_i-\hat y_i}{y_i}\right|$$

用**百分比**表达误差，跨不同量级的序列可比；但当 $y_i$ 接近 0 时，分母极小会让数值**爆炸**，是它的致命弱点。

**对称 MAPE（sMAPE）** 把分母改成真实值与预测值之和的一半，缓解了除以小值的问题：

$$\text{sMAPE} = \frac{1}{n}\sum_{i=1}^{n}\frac{|y_i-\hat y_i|}{(|y_i|+|\hat y_i|)/2}$$

**平均绝对标度误差 MASE（Mean Absolute Scaled Error）** 把误差除以一个**朴素基线**（如"用上一时刻值预测"）的误差，得到一个无量纲的相对分数：$\text{MASE}<1$ 说明模型比朴素基线好，$>1$ 说明还不如朴素基线。它对零值稳健，在时间序列里尤其常用。

## 分类指标

分类任务预测**类别**（如"是 / 否""欺诈 / 正常"）。

**准确率 accuracy** = 预测对的比例。简单，但在**类别不平衡**时极具误导性：若 99% 样本是"正常"，一个"全部预测正常"的废模型也有 99% 准确率，却一个欺诈都抓不到。

基于**混淆矩阵**（真正例 TP、假正例 FP、真负例 TN、假负例 FN）的指标更靠谱：

$$\text{precision（精确率）} = \frac{TP}{TP+FP},\qquad \text{recall（召回率）} = \frac{TP}{TP+FN}$$

- **精确率**：你报"阳性"的里面，有多少是真的？（关心"别误报"）
- **召回率**：所有真阳性里，你抓到了多少？（关心"别漏报"）

二者通常此消彼长，用 **F1 分数**（精确率与召回率的**调和平均**）综合：

$$F_1 = \frac{2\cdot\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}}$$

**ROC 曲线 / AUC**：调整判定阈值，画出"真正例率 vs 假正例率"曲线，曲线下面积 **AUC** 衡量模型整体的排序能力，$0.5$ 等于瞎猜，$1.0$ 完美。

## 损失函数 vs 评估指标

这两个概念很像，但角色不同：

- **[损失函数](../loss-function/)** 是训练时被**优化**（最小化）的对象，必须**可微**，好让[梯度下降](../gradient-descent/)工作（如 MSE、[交叉熵](../cross-entropy/)）。
- **评估指标** 是训练后向人**报告**的成绩，**不要求可微**，怎么贴近业务怎么来（如 MAE、F1、AUC、MASE）。

举例：分类训练时用**交叉熵**当损失（可微、好优化），但最终汇报常用 **F1 / AUC**（不可微，但更能反映"抓没抓到欺诈"）。一句话：**损失函数是"训练时给优化器看的"，评估指标是"训练后给人看的"。**

## 一个具体例子

```python
from sklearn.metrics import (mean_absolute_error, mean_squared_error,
                             r2_score, f1_score, classification_report)
import numpy as np

# 回归
y_true = [3.0, 5.0, 2.5, 7.0]
y_pred = [2.8, 4.5, 3.0, 6.0]
print("MAE :", mean_absolute_error(y_true, y_pred))
print("RMSE:", np.sqrt(mean_squared_error(y_true, y_pred)))
print("R2  :", r2_score(y_true, y_pred))

# 分类
yc_true = [0, 1, 1, 0, 1]
yc_pred = [0, 1, 0, 0, 1]
print("F1  :", f1_score(yc_true, yc_pred))
print(classification_report(yc_true, yc_pred))   # 精确率/召回率/F1 一次看全
```

## 为什么重要：要匹配业务目标

指标不是越多越好，而是要**对准你真正在乎的事**：

- 医疗筛查最怕**漏诊** → 优先看**召回率**。
- 垃圾邮件过滤最怕**误杀正常邮件** → 优先看**精确率**。
- 库存预测里大误差代价高 → 用会**重罚大误差**的 **RMSE**。
- 要向老板解释"平均差多少件" → 用单位直观的 **MAE**。

选错指标，等于优化了一个"看起来漂亮但没用"的目标。

## 在时间序列预测中的意义

- **数值预测**通常用 **RMSE / MAE**：RMSE 更在意偶发的大错，MAE 更稳健、更好解释。
- **慎用 MAPE**：序列里一旦出现**零值或极小值**，MAPE 会被放大到失真。这时改用 **sMAPE** 或 **MASE** 更稳。
- **优先用 MASE**：它拿模型误差和**朴素预测（用上一期的值当预测）**的误差相比，天然回答了"我的模型到底比'啥也不做'强多少"这个最该问的问题。
- **必须按时间顺序、在样本外（未来）评估**：用过去训练、在它没见过的未来时段打分，否则成绩没有意义（详见 [交叉验证](../cross-validation/) 中的前向验证）。
- **关注分步长（per-horizon）误差**：预测下一步通常准，预测很多步以后误差会**随预测步长增大**。把各个预测步长的误差**分开报告**，比只看一个总平均更有信息量。
- **永远和朴素基线比**：任何花哨模型，先确认它真的赢过"用昨天的值预测今天"这条朴素基线，否则复杂度毫无价值。

## 小结

- 评估指标 = 判断模型好坏的尺子；**选错尺子会误判**，要匹配业务目标，并在**测试集**上报告。
- 回归：MAE（稳健）、MSE/RMSE（重罚大误差、RMSE 同单位）、$R^2$、MAPE（怕零值）、sMAPE / MASE（更稳、可比）。
- 分类：accuracy（不平衡时会骗人）、precision、recall、F1、混淆矩阵、ROC/AUC。
- **损失函数**被优化（可微）、**评估指标**被报告（不必可微）——别混为一谈。
- 时间序列：按时间顺序在未来上评估，关注分步长误差，慎用 MAPE、善用 MASE，**永远和朴素基线比**。
