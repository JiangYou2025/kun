**编程**就是把一个想法，拆成计算机能一步步执行的明确指令。它是把数学和模型「跑起来」、做动手实验的基本功。本课程的所有案例都用 [Python](../python/)。

## 直观理解

编程很像写菜谱给一位**极其听话但毫无常识**的厨师：

- 你不能说「炒到差不多就行」——必须写清「中火翻炒 3 分钟」。
- 厨师严格照做，但你写错一步（盐写成糖），它绝不会纠正，只会忠实地做出错的菜。

所以编程的核心不是记住语法，而是**把模糊的想法拆解成精确、无歧义、有先后的步骤**——这种「计算思维」才是真本事，语法只是表达它的工具。

## 核心要点

几乎所有程序都由这几块积木搭成：

- **变量**：给数据起名字存起来，`lr = 0.001`。
- **数据类型**：数字、字符串、列表、字典等（见[数据结构](../data-structures/)）。
- **控制流**：
  - 条件 `if / else`：根据情况走不同分支。
  - 循环 `for / while`：重复做某件事。
- **函数**：把一段逻辑打包、命名、复用，避免重复代码。
- **模块/库**：别人写好的功能拿来即用，如 [NumPy](../numpy/)、[Pandas](../pandas/)。

写好代码的习惯：**命名清楚、函数短小、一个函数只做一件事、出错有提示**——这些属于[工程实践](../engineering-practice/)。

## 一个例子

把「算一条序列的滑动平均」这个想法翻译成代码：

```python
def moving_average(series, window):
    """对 series 做窗口为 window 的滑动平均，返回新列表"""
    if window <= 0:                      # 防御：参数检查
        raise ValueError("window 必须为正")
    result = []
    for i in range(len(series)):
        start = max(0, i - window + 1)   # 窗口左边界
        chunk = series[start : i + 1]    # 取窗口内的数
        result.append(sum(chunk) / len(chunk))
    return result

data = [10, 12, 14, 13, 15, 16]
print(moving_average(data, 3))
# [10.0, 11.0, 12.0, 13.0, 14.0, 14.666...]
```

注意它体现了所有积木：**函数**封装、**参数检查**（if）、**循环**遍历、**变量**存中间结果。等你学了[向量化](../vectorization/)，会发现 [NumPy](../numpy/)/[Pandas](../pandas/) 一行就能更快地做完同样的事——但理解循环版本，才懂向量化省了什么。

## 在时间序列预测中的意义

做时序预测，编程贯穿始终：

- **数据预处理**：读文件、对齐时间、补缺失、切滑动窗口，都是代码。
- **实现与改模型**：要让 **KUN / Kernel U-Net** 跑起来、调结构、加模块，必须能读懂和修改代码。
- **跑实验、画图、算指标**：每一个结论背后都是一段可重跑的脚本。

会编程，你才能从「看论文」走到「亲手验证、亲手改进」。**不会跑代码，模型对你就只是一张图。**

## 小结

- 编程 = 把想法拆成精确、有序、无歧义的指令；核心是计算思维，不是背语法。
- 积木：变量、数据类型、控制流（if/循环）、函数、库。
- 好代码：命名清楚、函数短小、有错误处理——延伸到[工程实践](../engineering-practice/)。
- 本课程用 [Python](../python/)；它是你做一切动手实验的入口。
