**学习率（learning rate, $\eta$）**是梯度下降每一步迈出的**步长**。它决定了"沿着梯度方向，一次走多远"。太大了会震荡甚至发散，太小了训练慢如蜗牛——它是深度学习中**最关键、最该优先调的超参数**。

## 直观理解

还是"蒙眼下山"。[反向传播](../backpropagation/)告诉你脚下最陡的下坡方向，学习率决定你**每一步迈多大**：

- **步子太大**：可能一步直接迈过谷底，到对面山坡上，再迈回来……来回**震荡**，甚至越走越高（**发散**）。
- **步子太小**：方向虽对，但走得极慢，训练要花很久，还可能卡在小坑里出不来。
- **步子刚好**：稳稳地、较快地走到谷底。

所以学习率不是"越大越快"也不是"越小越好"，而是要找一个**恰当的甜区**。

## 原理：它如何进入更新公式

参数更新的通用形式：

$$
\theta_{t+1} = \theta_t - \eta\, g_t
$$

- $\theta_t$：当前参数；$g_t$：[反向传播](../backpropagation/)算出的梯度；$\eta$：学习率。
- $\eta$ 直接**缩放**了每一步的移动量。$\eta$ 翻倍，步子翻倍。

它对收敛的影响可以从一个简单例子看出。最小化 $\mathcal{L}=\theta^2$（梯度 $g=2\theta$），更新变成 $\theta_{t+1} = \theta_t(1 - 2\eta)$：

- $\eta=0.1$：因子 $0.8$，**平稳收敛**到 0。
- $\eta=0.5$：因子 $0$，**一步到位**（理想，但实际曲面没这么巧）。
- $\eta=1.0$：因子 $-1$，在 $+1,-1$ 之间**永远震荡**。
- $\eta=1.5$：因子 $-2$，$|\theta|$ 越来越大，**发散**！

## 学习率调度（schedule）

固定学习率往往不是最优。常见做法是**先大后小**：

- **Warmup（预热）**：训练初期从很小的 $\eta$ 线性升到目标值，避免一开始就被巨大梯度带飞。
- **衰减（decay）**：训练后期逐步减小 $\eta$，让参数在谷底附近**精细微调**。常见有 step decay、余弦退火（cosine annealing）。

一条典型曲线：先 warmup 升上去，再余弦曲线缓缓降下来。

```python
import torch
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
# 余弦退火：lr 从 1e-3 沿余弦曲线降到接近 0
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=100)
for epoch in range(100):
    train_one_epoch(...)
    opt.step()
    sched.step()                 # 每个 epoch 更新一次学习率
    print(sched.get_last_lr())
```

## 怎么选学习率

- 常用起点：**Adam 用 $10^{-3}$**，SGD 用 $10^{-1}\sim10^{-2}$。
- **按 10 倍量级扫描**：试 $10^{-2}, 10^{-3}, 10^{-4}$，看哪个 loss 下降最快又不震荡。
- 看 loss 曲线诊断：**剧烈上下震荡 / 变 NaN → 调小**；**下降得很慢很平 → 调大**。

## 在时间序列预测中的意义

训练 [Kernel U-Net (KUN)](../../zh/kun/) 这类模型处理**长回看窗口**时，学习率尤其敏感：序列越长，梯度的尺度波动越大，过大的学习率更容易触发[梯度爆炸](../vanishing-exploding-gradient/)导致 loss 变 NaN。实践中常配合 [Adam](../adam/) + 适度学习率 + warmup + 余弦衰减，并在梯度爆炸时**先把学习率调小**。这是把 KUN 训稳的第一招。

## 小结

- 学习率 $\eta$ = 梯度下降的**步长**，出现在 $\theta_{t+1}=\theta_t-\eta g_t$。
- **太大震荡/发散，太小太慢**，要找甜区。
- 实战：从量级试起，配合 **warmup + 衰减**调度；它是最该优先调的超参数。
