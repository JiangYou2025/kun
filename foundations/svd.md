SVD（奇异值分解）把**任意**矩阵分解成"**旋转 → 缩放 → 旋转**"三步。它是 [PCA](../pca/)、降维、低秩近似、推荐系统等众多方法的数学基础。

## 直观理解

任何线性变换（矩阵），不管多复杂，本质上都可以拆成三个简单动作的组合：

1. **旋转**坐标系（不改变形状，只换看问题的角度）；
2. 沿新的坐标轴**拉伸 / 压缩**（每个方向缩放一个倍率）；
3. 再**旋转**到输出坐标系。

其中"缩放的倍率"就是**奇异值**，它们衡量该矩阵在各个主方向上"作用有多强"。奇异值大的方向是数据 / 变换的主要结构，奇异值小的方向往往是噪声或次要细节——**丢掉小奇异值 = 压缩 / 去噪**，这就是 SVD 强大的根源。

## 数学表达

任意矩阵 $A\in\mathbb{R}^{m\times n}$ 都可分解为：

$$
A=U\Sigma V^\top
$$

- $U\in\mathbb{R}^{m\times m}$ —— 正交矩阵，列为**左奇异向量**（输出空间的旋转）；
- $V\in\mathbb{R}^{n\times n}$ —— 正交矩阵，列为**右奇异向量**（输入空间的旋转）；
- $\Sigma\in\mathbb{R}^{m\times n}$ —— 对角矩阵，对角线是**奇异值** $\sigma_1\ge\sigma_2\ge\dots\ge 0$（缩放倍率）。

"正交"意味着 $U^\top U=I$，即纯旋转 / 反射、不改变长度。

**低秩近似（Eckart–Young 定理）**：只保留前 $k$ 个最大奇异值，

$$
A_k=\sum_{i=1}^{k}\sigma_i\,u_i v_i^\top
$$

是所有秩为 $k$ 的矩阵中**最接近** $A$ 的那一个（在 Frobenius / 谱范数意义下）。这正是用 SVD 做压缩与降维的理论保证。

## 一个具体例子

```python
import numpy as np
A = np.array([[3, 0],
              [0, 1],
              [0, 0]], dtype=float)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
print(np.round(s, 3))           # 奇异值 [3. 1.]  → x 方向作用更强
# 用最大的 1 个奇异值做秩-1 近似
A1 = s[0] * np.outer(U[:, 0], Vt[0])
print(np.round(A1, 3))          # 保留主结构，丢掉次要的那一维
```

奇异值 `[3, 1]` 表明这个变换在第一个方向上的作用是第二个方向的 3 倍；只留下最大的奇异值就得到最佳的秩-1 近似。

## 为什么重要 / 用在哪

- **PCA / 降维**：对数据矩阵做 SVD，前几个奇异向量就是主成分。
- **图像 / 数据压缩**：保留少数大奇异值即可重建出接近原图的结果。
- **推荐系统**：对"用户 × 物品"评分矩阵做低秩分解，预测缺失评分。
- **数值稳定**：用奇异值计算矩阵的秩、条件数、伪逆（最小二乘解）。

## 在时间序列预测中的意义

- 多变量时间序列排成矩阵后，SVD / 低秩分解能提取少数**共同因子**，去噪并降维，为预测模型提供更紧凑的输入。
- "用低秩结构概括复杂数据"的思想与 KUN（Kernel U-Net）通过下采样 / 核映射**提取多尺度主结构**异曲同工——都是抓主干、压细节。
- 模型权重的奇异值谱还能用于分析与压缩网络（低秩适配、剪枝）。

## 小结

- 任意矩阵都能写成 $A=U\Sigma V^\top$：旋转—缩放—旋转。
- 奇异值的大小代表各方向"作用强度"，大者为主结构、小者多为噪声。
- 保留前 $k$ 个奇异值给出最佳低秩近似，是 PCA、压缩、降维、推荐的共同基石。
