## 9.1 AR 模型

**自回归 AR(p)**：用过去 $p$ 步的线性组合预测下一步。

$$x_t = c + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p} + \varepsilon_t$$

核心思想：**序列的未来是它自己过去的函数**。参数 $\phi$ 由最小二乘或 Yule-Walker 方程求解。

## 9.2 MA 模型

**移动平均 MA(q)**：用过去 $q$ 步的预测误差的线性组合。

$$x_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}$$

MA 模型捕获的是**短期冲击的衰减效应**。

## 9.3 ARIMA

**ARIMA(p, d, q)** = 差分 $d$ 次 + AR(p) + MA(q)。

Box-Jenkins 三步法：
1. **识别**：看 ACF/PACF 选 p、d、q
2. **估计**：最大似然估计参数
3. **诊断**：检查残差是否为白噪声

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(train, order=(2, 1, 1)).fit()
forecast = model.forecast(steps=24)
```

## 9.4 SARIMA

**SARIMA(p,d,q)(P,D,Q)m**：在 ARIMA 基础上加季节性成分。

- $(P,D,Q)$：季节性的 AR、差分、MA 阶数
- $m$：季节周期（12=年、7=周）

SARIMA 是经典时间序列预测的"瑞士军刀"——简单、可解释、很多场景下效果出奇好。

## 9.5 Auto-ARIMA

手动选 p/d/q 太麻烦？`pmdarima` 的 `auto_arima` 自动搜索最优阶数：

```python
import pmdarima as pm
model = pm.auto_arima(train, seasonal=True, m=12)
```

## 9.6 直觉与选阶

- **AR vs MA 的直觉**：AR 说"未来由过去的**值**决定"（惯性、向均值回归）；MA 说"未来由过去的**冲击 / 误差**决定"（一次性扰动的余波）。
- **怎么定 p、d、q**：先用单位根检验定 $d$（第 5 讲），再用 ACF / PACF 读 $p$、$q$（第 6 讲），最后用 AIC / BIC 在候选里挑。
- **ARIMA 的边界**：它本质是**线性**且默认**单变量**的模型；强非线性、多变量耦合的场景要交给后面的 ML / 深度模型。
