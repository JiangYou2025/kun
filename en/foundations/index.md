## Why these foundation courses?

The main course, [Introduction to Time Series](../course/), relies on some mathematical language and machine learning ideas. If you get stuck in a lecture, it is most likely because one of the foundations is not yet solid. These four foundation courses are the **minimal prerequisites** for exactly that purpose — they only lay out the framework and the core concepts to help you build intuition quickly; when you need to go deeper, turn to a dedicated textbook.

## How to use them

- **Look things up as needed**: there is no need to read everything from the start; come back for the relevant concept when you get stuck in the main course.
- **Framework first**: each course is a "concept map" that points out "what there is, why it matters, and how the pieces connect"; in-depth derivations are left to dedicated textbooks.
- **Suggested order**: math → computer science → machine learning → deep learning, as each builds on the ones before it.
