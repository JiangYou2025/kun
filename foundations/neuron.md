**神经元（neuron）是神经网络里最小的计算单元**：它把若干输入加权求和，加上一个偏置，再送进一个[激活函数](../activation-function/)，输出一个数。所有的深度模型，归根到底都是成千上万个这样的小单元堆出来的。

## 直观理解

你可以把一个神经元想象成一个**会打分的小裁判**。它面前摆着几个特征（比如某只股票今天的开盘价、成交量、昨天的收盘价），它对每个特征都有一个「我有多看重它」的权重，然后把它们按权重加起来得到一个总分。如果总分够高（超过某个门槛），它就「兴奋」起来、输出一个较大的值；否则就保持安静。

- **权重 $w_i$**：表示「这个输入对我有多重要」。正权重表示该输入越大越倾向于激活，负权重则相反。
- **偏置 $b$**：相当于这个裁判的「基准线」或「脾气」。偏置大，说明它很容易兴奋；偏置很负，说明它很难被激活。
- **激活函数**：决定「总分如何变成输出」，并且引入了关键的**非线性**。

一个神经元本身很笨，只会做一件简单的事；但把很多神经元连成网络，它们就能逼近极其复杂的函数。

## 数学表达

单个神经元的计算分两步。先做**线性加权求和**（也叫预激活，记作 $z$）：

$$ z = \sum_{i=1}^{n} w_i x_i + b = \mathbf{w}^\top \mathbf{x} + b $$

其中：

- $\mathbf{x} = (x_1, \dots, x_n)$ 是输入向量，$n$ 是输入特征的个数；
- $\mathbf{w} = (w_1, \dots, w_n)$ 是权重向量，是神经元要**学习**的参数；
- $b$ 是偏置，也是要学习的参数；
- $\mathbf{w}^\top \mathbf{x}$ 是向量点积，即 $w_1x_1 + w_2x_2 + \dots + w_nx_n$。

然后过一个激活函数 $\sigma$ 得到**输出 $a$**（activation）：

$$ a = \sigma(z) = \sigma(\mathbf{w}^\top \mathbf{x} + b) $$

如果没有 $\sigma$（即 $\sigma$ 是恒等函数），那么无论叠多少层，整个网络都只是一连串线性变换的复合，仍然只是一个线性函数——这就是为什么[激活函数](../activation-function/)不可或缺。

## 一个具体例子

假设一个神经元有两个输入 $x_1, x_2$，权重 $\mathbf{w} = (0.5,\ -1.2)$，偏置 $b = 0.3$，激活函数用 ReLU（$\mathrm{ReLU}(z)=\max(0,z)$）。

给定输入 $\mathbf{x} = (4,\ 1)$：

$$ z = 0.5 \times 4 + (-1.2)\times 1 + 0.3 = 2.0 - 1.2 + 0.3 = 1.1 $$
$$ a = \mathrm{ReLU}(1.1) = 1.1 $$

再换一个输入 $\mathbf{x} = (1,\ 3)$：

$$ z = 0.5\times 1 + (-1.2)\times 3 + 0.3 = 0.5 - 3.6 + 0.3 = -2.8 $$
$$ a = \mathrm{ReLU}(-2.8) = 0 $$

可以看到，第二个输入让神经元「沉默」了。用代码写出来就是：

```python
import numpy as np

w = np.array([0.5, -1.2])
b = 0.3

def neuron(x):
    z = w @ x + b          # 加权求和
    return max(0.0, z)     # ReLU 激活

print(neuron(np.array([4, 1])))  # 1.1
print(neuron(np.array([1, 3])))  # 0.0
```

## 为什么重要 / 用在哪

神经元是理解一切深度学习结构的**原子**：

- 把一层里的多个神经元并排放，就得到一个**全连接层**；多个全连接层叠起来就是 [MLP](../mlp/)。
- 在 [CNN](../cnn/) 里，神经元共享权重并只看局部输入，就成了卷积核。
- 在 [RNN](../rnn/) 里，神经元额外接收上一时刻的隐藏状态。

理解了「加权求和 + 激活」这一步，你就能看懂[前向传播](../forward-propagation/)（沿网络把这步重复执行）和[反向传播](../backpropagation/)（反过来求每个 $w_i, b$ 的梯度）。

## 在时间序列预测中的意义

在做预测时，神经元接收的「输入」往往是**历史窗口里的若干数值**或它们的特征。比如要用过去 96 个时间点预测未来，每个神经元就在对这 96 个数（或更高层抽取出的特征）做加权组合。本站的旗舰模型 [Kernel U-Net (KUN)](../u-net/) 也不例外——它在多个尺度上用这种「加权求和 + 非线性」的基本单元来提炼时间模式，只是把它们组织成了 U 形的多尺度结构。

## 小结

- 神经元 = **加权求和 $\mathbf{w}^\top\mathbf{x}+b$，再过激活函数 $\sigma$**。
- $\mathbf{w}$ 和 $b$ 是要学习的参数，由训练（[反向传播](../backpropagation/) + [优化器](../optimizer/)）自动调出来。
- **激活函数带来的非线性**才是网络能拟合复杂函数的关键；去掉它，再深也只是线性模型。
- 一切复杂架构都是神经元的不同「排列组合」。
