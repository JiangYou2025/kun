**CNN（Convolutional Neural Network，卷积神经网络）** 用一个个小巧的**卷积核**在数据上滑动，提取**平移不变的局部模式**。它最早在图像上大放异彩，但同样适用于时间序列——只要把二维卷积换成沿时间轴的**一维卷积**。

## 直观理解

设想你用一个小放大镜（卷积核，比如宽度 3）从左到右扫过一条时间序列。每滑到一个位置，放大镜就回答一个问题："这一小段有没有我关心的形状？"——比如一个上升沿、一个尖峰、一个台阶。

关键在于：**同一个放大镜在所有位置共用同一套参数**。这带来两个好处：

- **平移不变性**：无论尖峰出现在序列开头还是结尾，同一个核都能识别它；
- **参数共享**：不像 [MLP](../mlp/) 给每个位置配一组独立权重，CNN 整条序列只用一组核参数，参数量小得多、更不易[过拟合](../overfitting/)。

## 原理

一维卷积：核 $\mathbf{w}$ 长度为 $k$，在输入 $\mathbf{x}$ 上滑动，输出第 $t$ 个值为：

$$
y_t = \sum_{i=0}^{k-1} w_i \, x_{t+i} + b
$$

- $x_{t+i}$：输入在第 $t+i$ 个时刻的值；
- $w_i$：核的第 $i$ 个权重，是要学习的参数；
- $k$：核大小（kernel size），即每次看多宽的局部窗口；
- $b$：偏置；
- $y_t$：该位置的输出，称为"特征图"上的一个点。

卷积层后通常接非线性[激活函数](../activation-function/)，再接**池化（pooling）**做下采样——例如最大池化在每个小窗口取最大值：

$$
p_t = \max\left(y_{2t},\, y_{2t+1}\right)
$$

下采样后序列变短（这里长度减半），但每个点"看到的范围"（**感受野**）变大。**多层卷积 + 下采样叠加，让网络从局部细节逐步看到更大尺度的模式**——这正是后面 U-Net 与 KUN 多尺度思想的源头。

几个常用旋钮：

- **stride（步长）**：核每次跳几步，步长 > 1 也能下采样；
- **padding（填充）**：两端补零，让输出和输入等长；
- **dilation（膨胀）**：核的采样点之间留空隙，不增参数就扩大感受野（时序里常用的因果膨胀卷积，如 WaveNet/TCN）。

## 一个具体例子

用一个长度 3 的核 $\mathbf{w} = [1, 0, -1]$（一个简单的"边缘检测器"）卷输入 $\mathbf{x} = [3, 3, 5, 5, 5]$，无 padding、stride 1，$b=0$：

- $y_0 = 1\cdot3 + 0\cdot3 + (-1)\cdot5 = -2$
- $y_1 = 1\cdot3 + 0\cdot5 + (-1)\cdot5 = -2$
- $y_2 = 1\cdot5 + 0\cdot5 + (-1)\cdot5 = 0$

输出 $[-2, -2, 0]$：在 3→5 的"跳变"处给出非零响应，在平坦处给出 0。这就是卷积核在"检测局部变化"。

PyTorch 版本：

```python
import torch.nn as nn

conv = nn.Conv1d(in_channels=1, out_channels=16,
                 kernel_size=3, padding=1)   # 16 个核，输出等长
# 输入形状: (批量, 通道=1, 时间长度)
```

## 为什么重要 / 用在哪

- **高效**：参数少、计算可并行，训练快。
- **局部特征专家**：擅长抓"形状类"模式——周期波形、突变、季节性片段。
- **多尺度基石**：层层下采样形成由细到粗的特征金字塔，是图像分割 [U-Net](../u-net/) 和众多时序模型的结构基础。

## 在时间序列预测中的意义

沿时间轴的**一维卷积 + 下采样**，正是本站主推模型 **Kernel U-Net (KUN)** 的概念祖先。CNN 告诉我们一个核心直觉：

> **在不同时间分辨率上看序列，能同时捕捉短期细节和长期趋势。**

底层卷积看到的是"分钟级"的抖动，下采样几次后看到的是"小时级、天级"的趋势。KUN 继承了这种**多尺度（多分辨率）**思路：它在时间轴上逐级下采样得到由细到粗的多个视图，但**把厚重的卷积块换成更轻量的可学习"核"**，从而更省算力地兼顾长短程信息。所以理解 1D 卷积与下采样，是理解 KUN 的第一步。

## 小结

- CNN 用**共享的卷积核**滑动提取**局部、平移不变**的模式。
- **下采样 + 多层**让感受野逐级增大，形成由细到粗的多尺度特征。
- 一维卷积天然适合时间序列，是 [U-Net](../u-net/) 和 Kernel U-Net 多尺度结构的概念源头。
