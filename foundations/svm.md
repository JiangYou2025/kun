**SVM（支持向量机，Support Vector Machine）**是一种分类（也能做回归）的方法，核心思想是：在两类数据之间找到一条**间隔最大**的分界线；再借助**核技巧**，它还能轻松处理非线性问题。

## 直观理解

假设平面上有两堆点，一堆红、一堆蓝，你要画一条线把它们分开。能分开的线有无数条——但哪条「最好」？

SVM 的回答是：**找那条让两类离它都尽量远的线**。形象地说，想象在两类之间修一条尽可能**最宽的街道（street）**，街道正中央那条线就是分界线，街道的宽度就是**间隔（margin）**。街道越宽，模型对新数据的判断就越有「余量」，**泛化能力**也越好。

而真正决定这条街道宽度和位置的，只有那几个**贴着街道边缘的点**——它们被称为**支持向量（support vectors）**。其余离得远的点，挪一挪根本不影响结果。这正是 SVM 名字的由来，也是它的一大特点：**模型只由少数关键样本决定**。

## 原理：最大间隔

设分界面（超平面）为

$$w^\top x + b = 0$$

对一个点 $x$，$w^\top x + b$ 的符号告诉我们它在分界面的哪一侧。可以推导出，两条边缘之间的**间隔**为

$$\text{margin} = \frac{2}{\|w\|}$$

要让间隔**最大**，等价于让 $\|w\|$ **最小**。于是 SVM 的优化目标写成一个漂亮的形式：

$$\min_{w,b}\ \frac{1}{2}\|w\|^2 \quad \text{s.t.}\quad y_i\,(w^\top x_i + b) \ge 1,\ \forall i$$

这里 $y_i \in \{-1, +1\}$ 是类别标签。约束 $y_i(w^\top x_i + b)\ge 1$ 的意思是「每个点都要待在街道正确的一侧、并且在街道边缘之外」。**恰好落在边缘上**（即等号成立）的那些点，就是**支持向量**。

## 软间隔与参数 C

现实数据往往有噪声、有重叠，硬要求「所有点都分对」会让间隔变得很窄、甚至无解。于是引入**软间隔（soft margin）**：允许少数点越界，但要为越界付出代价。优化目标变成

$$\min_{w,b}\ \frac{1}{2}\|w\|^2 + C\sum_i \xi_i$$

其中 $\xi_i \ge 0$ 是每个点的「**松弛变量**」，衡量它越界多少；$C$ 是**惩罚系数（正则化参数）**，控制权衡：

- **C 大** → 强烈惩罚越界 → 尽量分对每个点 → 间隔窄，容易**过拟合**；
- **C 小** → 容忍更多越界 → 间隔宽，更稳健，但可能**欠拟合**。

所以 $C$ 本质上是在「间隔宽度」和「分类错误」之间做平衡，是必须调的关键超参。

## 核技巧（kernel trick）

如果数据根本不能用一条直线分开怎么办？SVM 的杀手锏是**核技巧**：把数据**隐式地**映射到一个更高维的空间，在那里它们也许就线性可分了——而且**不用真的算出高维坐标**，只需要一个**核函数（kernel）** $K(x_i, x_j)$ 来代替高维空间里的内积。常见核函数：

- **线性核**：$K(x, x') = x^\top x'$，就是普通线性 SVM。
- **多项式核**：$K(x, x') = (x^\top x' + c)^d$，能拟合多项式形状的边界。
- **RBF（高斯）核**：$K(x, x') = \exp(-\gamma\|x - x'\|^2)$，最常用、最灵活。$\gamma$ 控制每个点的「影响半径」：$\gamma$ 大 → 影响范围小、边界弯曲、易过拟合；$\gamma$ 小 → 边界平滑。

回归任务用的是 **SVR（支持向量回归）**：思路对称——不再追求「间隔内没有点」，而是允许预测落在真实值附近一个 $\varepsilon$ 宽的「管道」里，只惩罚跑出管道的点。

## 一个具体例子（sklearn）

```python
from sklearn.svm import SVC
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=200, noise=0.2, random_state=0)  # 非线性数据

# 先标准化再上 RBF 核 SVM —— 标准化对 SVM 至关重要
clf = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma="scale")   # C 和 gamma 是关键超参
)
clf.fit(X, y)

print("准确率:", clf.score(X, y))
print("支持向量个数:", clf.named_steps["svc"].n_support_)
```

注意必须先做**特征缩放（StandardScaler）**：核函数（尤其 RBF）依赖样本间距离，量纲不一致会让大数值特征「淹没」其他特征。

## 为什么重要（用在哪）

- 在**中小规模、高维**数据上表现很强——文本分类、生物信息这类「特征很多、样本不算特别多」的场景一度是 SVM 的主场。
- **最大间隔**带来良好的泛化，对噪声有一定鲁棒性。
- 核技巧让它能在不显式升维的情况下捕捉复杂的**非线性**关系。
- 它和[决策树](../decision-tree/)、[集成学习 / GBDT](../ensemble-gbdt/)等属于不同的[模型族](../model-families/)，各有擅长的数据形态，值得对比试用。

## 在时间序列预测中的意义

在时间序列里，可以用 **SVR + 滞后特征**来做预测：把过去几期 $y_{t-1}, \dots, y_{t-p}$ 当输入，预测 $y_t$。相比线性自回归，带 RBF 核的 SVR 能捕捉滞后特征之间的**非线性关系**。实践要点：

- **务必做特征缩放**——这对 SVM/SVR 不是可选项，而是必需。
- **核函数选择**决定了能表达多复杂的模式，RBF 是默认首选。
- **调 C 和 gamma 极其关键**，通常用交叉验证做网格搜索；调不好很容易过拟合或欠拟合。
- 注意 SVM **在大数据上较慢**（训练复杂度大致随样本数的平方甚至更高增长），数据量很大时，[集成学习 / GBDT](../ensemble-gbdt/)往往又快又准，是更实际的选择。

## 小结

- **SVM = 找最大间隔的分界超平面**：$w^\top x + b = 0$，间隔 $=\frac{2}{\|w\|}$，最大化间隔 ⇔ 最小化 $\frac12\|w\|^2$。
- **支持向量**是贴在间隔边缘上的关键样本，模型只由它们决定。
- **软间隔 + 参数 C** 在「间隔宽度」和「分类错误」之间权衡。
- **核技巧**（线性 / 多项式 / RBF）隐式升维，处理非线性；回归版本是 **SVR**。
- 适合中小规模高维数据；时间序列里可用 **SVR 在滞后特征上预测**，但要**缩放特征、细调 C 和 gamma**，大数据上不如 [GBDT](../ensemble-gbdt/) 高效。
