> 这是一张**概念地图**：点出机器学习"在做什么、有哪些工具、怎么算学好了"，深入算法留给专门教材。

## 1. 什么是机器学习？

不显式编写规则，而是**从数据中学习**映射 $f_\theta: X \to y$。

- **监督学习**：有标签，学输入到输出（回归 / 分类）
- **无监督学习**：无标签，找结构（聚类 / 降维）
- **强化学习**：与环境交互，最大化累计奖励
- 时间序列预测通常被建模为**监督学习**（过去窗口 → 未来值）

## 2. 主流模型族

- **线性模型**：线性 / 逻辑回归——简单、可解释的起点
- **K 近邻 (KNN)**：靠"邻居"投票
- **决策树**：可解释的 if-else 划分
- **集成方法**：随机森林、梯度提升 (GBDT / XGBoost)——表格数据的强基线
- **支持向量机 (SVM)**：最大间隔分类
- **聚类与降维**：K-means、PCA

## 3. 训练流程

- **损失函数**：回归用 MSE / MAE，分类用交叉熵
- **优化**：梯度下降或解析解，最小化损失
- **数据切分**：训练 / 验证 / 测试
- **交叉验证**：更稳健的超参选择（**时间序列要用按时间顺序的切分**，不能随机打乱）
- **超参数调优**：网格 / 随机 / 贝叶斯搜索

## 4. 泛化：核心挑战

目标是在**没见过**的数据上表现好，而非记住训练集。

- **欠拟合**：太简单，高偏差
- **过拟合**：太复杂，记住噪声，高方差
- **偏差—方差权衡**：找复杂度的平衡点
- **正则化**：$\ell_1$ / $\ell_2$、早停、剪枝——给模型加约束

## 5. 评估指标

- **回归**：MSE、RMSE、MAE、MAPE、$R^2$
- **分类**：准确率、精确率 / 召回率、F1、ROC-AUC
- **关键**：指标要匹配业务目标，并在**测试集**上报告
