**无监督学习（unsupervised learning）** 指的是：训练数据**没有任何标签**，没有“标准答案”可对照，模型的目标是自己从数据里**发现隐藏的结构和规律**。

## 直观理解

如果说[监督学习](../supervised-learning/)像“有老师批改、对着答案做练习”，那么无监督学习就像**没有老师**：你面前摊着一大堆数据，没人告诉你哪个对、哪个属于哪一类，你得自己观察、归纳、找出其中的门道。

举个生活中的例子：你把一筐没贴标签的水果倒在桌上，没人告诉你它们叫什么。但你会自然地按“大小、颜色、形状”把它们**分成几堆**——红的圆的一堆、黄的长的一堆。你并不知道每堆“正确的名字”，但你发现了数据本身的**组织结构**。这就是无监督学习在做的事。

因为没有标签，无监督学习的目标不是“预测对不对”，而是“**揭示数据内在的模式**”。

## 主要任务

无监督学习有几类典型任务：

- **聚类（clustering）**：把相似的样本自动分到同一组。代表算法是 **K-means**。详见[聚类](../clustering/)。
- **降维（dimensionality reduction）**：在尽量保留信息的前提下，把高维数据压缩到低维，便于可视化和后续建模。代表方法是主成分分析，详见 [PCA（主成分分析）](../pca/)。
- **异常检测（anomaly detection）**：找出与大多数样本明显不同的“离群点”，比如信用卡盗刷、设备故障。
- **密度估计（density estimation）**：估计数据在空间中的分布，搞清楚“数据通常出现在哪里”。

## 原理（数学直觉）

不同任务背后的优化目标不同，但都围绕“度量相似/信息”展开：

**聚类**：把 $n$ 个样本分到 $K$ 组，使**组内距离尽量小**（同组样本彼此相似）。K-means 最小化所有样本到其所属簇中心 $\mu_k$ 的距离平方和：

$$
\min_{\{\mu_k\}}\ \sum_{k=1}^{K}\ \sum_{x \in C_k} \lVert x - \mu_k \rVert^2
$$

其中 $C_k$ 是第 $k$ 个簇，$\mu_k$ 是它的中心。

**降维（PCA）**：寻找一组新的坐标方向，使数据**投影后的方差最大**——方差越大，保留的信息越多。它等价于找到协方差矩阵最大特征值对应的特征向量方向。直觉是：把数据“最舒展”的几个方向留下，把几乎没变化的方向丢掉。

注意：这两类目标里都**没有出现标签 $y$**，只有数据 $x$ 自身——这正是“无监督”的标志。

## 一个具体例子

用 `scikit-learn` 做一次 K-means 聚类。注意：我们只给 `X`，**完全不提供标签**：

```python
from sklearn.cluster import KMeans
import numpy as np

# 只有输入 X，没有 y！每行是一个样本的两个特征
X = np.array([
    [1, 2], [1.5, 1.8], [1, 0.6],     # 看起来是一堆
    [8, 8], [9, 11], [8.5, 9],        # 看起来是另一堆
])

model = KMeans(n_clusters=2, n_init=10, random_state=0)
labels = model.fit_predict(X)   # 自动把样本分成 2 组

print(labels)            # 例如 [0 0 0 1 1 1]
print(model.cluster_centers_)   # 两个簇的中心
```

模型并不知道“正确分组”是什么，它只是根据样本间的距离，自己找出了两个聚集的中心。换成 PCA 也类似：`from sklearn.decomposition import PCA`，用 `PCA(n_components=2).fit_transform(X)` 即可把高维数据压到 2 维，全程同样不需要标签。

## 为什么重要（用在哪）

现实世界里，**带标签的数据往往很贵**——需要人工标注，耗时耗钱；而**无标签数据则海量易得**。无监督学习让我们能直接从这些原始数据里挖价值：

- 用**聚类**做客户分群、文档归类、图像分组。
- 用**降维**压缩数据、去噪、做可视化探索。
- 用**异常检测**发现欺诈、入侵、故障。

它常常是建模流程的**第一步**：先无监督地理解数据结构，再决定后续怎么处理。与[监督学习](../supervised-learning/)（有标签、学映射）的根本区别就在于——**有没有标准答案**。

## 在时间序列预测中的意义

虽然预测本身是[监督学习](../supervised-learning/)任务，但无监督学习在时间序列里是非常有力的“辅助工具”：

- **对相似序列/片段聚类**：当你手头有成百上千条序列（比如很多门店的销量），可以先**聚类**把行为相似的序列分到一组，对每组分别建模，往往比“一个模型打天下”更准。
- **对大量相关序列降维**：当变量极多时，用 [PCA](../pca/) 把众多相关序列压成少数几个**主成分**，既减少噪声又降低计算量。
- **异常检测**：在序列中识别突变点、传感器故障或异常事件，避免它们污染训练数据或误导预测。
- **把聚类标签 / PCA 成分当作特征**：在监督化的预测表格里，额外加入“该序列属于哪一类”或“前几个主成分”作为特征，常能显著提升预测效果。
- **状态识别（regime detection）**：识别市场的牛/熊阶段、设备的正常/异常运行状态等不同“状态段”，让预测模型针对不同状态采取不同策略。

一句话：**无监督学习帮你“看懂”数据的结构，监督学习再据此“做出”预测。** 两者常常配合使用。

## 小结

- **无监督学习** = 数据**没有标签**，目标是发现隐藏结构，而非预测标准答案。
- 主要任务：**聚类**（分组）、**降维**（压缩，如 PCA）、**异常检测**、**密度估计**。
- 原理直觉：聚类**最小化组内距离**，PCA**最大化投影方差**，目标里都不含标签 $y$。
- 价值在于：无标签数据海量易得，能直接挖掘结构、做分群、去噪、找异常。
- 在时间序列中常作**辅助**：序列聚类、降维、异常检测、提供额外特征、状态识别，与[监督学习](../supervised-learning/)配合发力。
