## 8.1 为什么先学经典模型

在深度学习之前，统计学家用几十年打磨出了一套又简单又可解释的方法——ARIMA 家族。它至今仍是**单变量、短中序列预测的强基线**：参数少、训练快、每个系数都有清晰含义，而且在数据不多时常常打败花哨的神经网络。前几讲学的平稳性（第 6 讲）和自相关（第 7 讲）正是为这一讲铺路——现在我们把这些工具组装成完整模型。

## 8.2 AR：未来是过去的值

**自回归 AR(p)**：用过去 $p$ 步的线性组合预测下一步。

$$x_t = c + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p} + \varepsilon_t.$$

这正是第 3 讲那个线性模型的正式版。核心思想：**序列的未来是它自己过去的函数**。参数 $\phi$ 由最小二乘或 Yule-Walker 方程求解。$\phi_1$ 接近 1 表示强惯性，接近 0 表示很快回归均值。

## 8.3 MA：未来是过去的“意外”

**移动平均 MA(q)**：用过去 $q$ 步的**预测误差**的线性组合。

$$x_t = c + \varepsilon_t + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q}.$$

直觉对比：AR 说"未来由过去的**值**决定"（惯性、向均值回归）；MA 说"未来由过去的**冲击 / 误差**决定"（一次性扰动的余波）。两者捕捉的是序列记忆的两种不同形式。

## 8.4 ARIMA：差分 + AR + MA

真实序列往往不平稳，所以先差分再建模。**ARIMA(p, d, q)** = 差分 $d$ 次（把序列变平稳）+ AR(p) + MA(q)。经典的 **Box-Jenkins 三步法**正好用上前几讲的工具：

1. **识别**：用单位根检验定 $d$（第 6 讲），用 ACF/PACF 读 $p$、$q$（第 7 讲）。
2. **估计**：最大似然估计参数。
3. **诊断**：检查残差是否为白噪声（第 7 讲的 Ljung-Box）。

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(train, order=(2, 1, 1)).fit()
forecast = model.forecast(steps=24)
```

## 8.5 SARIMA：加上季节

**SARIMA(p,d,q)(P,D,Q)$_m$** 在 ARIMA 上叠一层季节成分：$(P,D,Q)$ 是季节性的 AR / 差分 / MA 阶数，$m$ 是季节周期（12=年、7=周）。它是经典预测的"瑞士军刀"——简单、可解释，在强季节数据上效果出奇好。

## 8.6 Auto-ARIMA：自动选阶

手动读 ACF/PACF 选 $p,d,q$ 很费劲，`pmdarima` 的 `auto_arima` 会自动搜索、按 **AIC / BIC** 挑最优组合：

```python
import pmdarima as pm
model = pm.auto_arima(train, seasonal=True, m=12)
```

## 8.7 选阶与边界

- **怎么定 p, d, q**：先单位根检验定 $d$，再 ACF/PACF 给候选 $p,q$，最后用 AIC/BIC 在候选里挑——信息准则会在"拟合好"和"别太复杂"之间权衡。
- **ARIMA 的边界**：它本质是**线性**且默认**单变量**的。强非线性、多变量耦合的场景，要交给后面的深度模型（第 9–11 讲）；指数平滑这条平行的经典路线放在第 12 讲。
- **永远先报基线对比**：哪怕用了 SARIMA，也要和"季节朴素法"比一比，证明它真的更好。
