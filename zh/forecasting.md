## 预测的工作流

一个靠谱的预测项目几乎总是遵循同一个循环：

1. **定义任务。** 你要预测什么？提前多久（时域 $H$）？多久预测一次？
2. **准备数据。** 处理缺失值、重采样到固定频率、处理离群点。
3. **按时间切分。** 用过去训练，用较近的一段验证，用最近的一段测试。**绝不打乱顺序。**
4. **先建立基线。** 如果你花哨的模型连基线都打不过，那问题出在模型上。
5. **训练并调优**逐步更强的模型。
6. **评估**——在留出数据上用合适的指标评估。
7. **监控**——上线后持续监控，随着世界漂移而重新训练。

> 初学者最常犯的错误，就是跳过第 3 步或第 4 步。没有诚实的按时间切分和一个可比的基线，排行榜上的数字毫无意义。

## 你必须打败的基线

永远先算这些——它们几乎免费，却出奇地强：

- **朴素 / 持续法：** 明天 = 今天，即 $\hat{x}_{t+1} = x_t$。
- **季节性朴素：** 这周一 = 上周一，即 $\hat{x}_{t+1} = x_{t+1-s}$，$s$ 为季节长度。
- **移动平均 / 漂移：** 延续最近的平均值或最近的斜率。

## 模型全景

### 1. 经典统计模型
- **ARIMA**——建模自相关与差分；适合单条、规律良好的序列。
- **指数平滑（ETS / Holt-Winters）**——对近期观测赋更大权重；在趋势 + 季节性明显时表现优异。

*优点：* 可解释，小数据上很强。*局限：* 一次只能处理一条序列，难以应对众多相互作用的变量和长时域。

### 2. 机器学习模型
- **梯度提升（XGBoost、LightGBM）** 配合人工特征（滞后项、滑动均值、星期几等日历特征）。

*优点：* 能处理大量协变量，鲁棒。*局限：* 特征工程要靠你手工来做。

### 3. 深度学习模型
- **RNN / LSTM / GRU、TCN 和 Transformer** 直接从原始窗口里学习时间规律。
- **现代预测模型**——PatchTST、DLinear、N-BEATS，以及 **Kernel U-Net (KUN)**——专为长时域、多变量预测而设计。

*优点：* 能跨多条序列学习复杂的、共享的规律；可扩展到长时域。*局限：* 需要更多数据和算力。

## 选择评价指标

指标定义了对*你的*问题来说"好"到底意味着什么。

| 指标 | 公式 | 何时使用 |
|---|---|---|
| **MAE** | $\frac{1}{H}\sum\lvert x_t-\hat{x}_t\rvert$ | 想要原始单位的误差，且对离群点鲁棒 |
| **RMSE** | $\sqrt{\frac{1}{H}\sum (x_t-\hat{x}_t)^2}$ | 希望对大误差惩罚更重 |
| **MAPE** | $\frac{100}{H}\sum\frac{\lvert x_t-\hat{x}_t\rvert}{\lvert x_t\rvert}$ | 需要无量纲的百分比（避免接近 0 的值）|

报告指标时一定要**和基线对比**，不要孤立地看。

## 按时间做验证

因为不能打乱顺序，要使用**滚动 / 扩展窗口交叉验证**：训练到某个时间点，预测下一段，向前滑动，重复。这模拟了模型实际使用的方式，并给你一个误差的分布，而不是一个碰运气的数字。

```
|--- 训练 ---|--- 测试 ---|
|------ 训练 ------|--- 测试 ---|
|--------- 训练 ---------|--- 测试 ---|
```

## 单步 vs. 多步

要预测时域 $H > 1$，有两种做法：

- **迭代（递归）：** 先预测一步，把它作为输入再喂回去，循环。简单，但误差会累积。
- **直接 / 多输出：** 一次性预测全部 $H$ 步。在长时域上更稳定——而这正是 **KUN** 生成预测的方式。
