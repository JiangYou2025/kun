## 远古 — 19 世纪：手工记录与手算

这个阶段没有"计算机"，使能技术是**文字与历法**（能把观测记下来）、**对数表与计算尺**（把繁重的乘除变成加减），以及 19 世纪出现的**机械模拟计算机**。任务的上限，就是一个人用纸笔能算多少。

| 年代 | 任务 | 使能技术 / 产品 | 一句话：技术如何让任务成为可能 |
|------|------|----------------|------------------------------|
| ~前 3000 | 洪水 / 天象预测 | 历法、泥板 / 纸草记录、周期表 | 尼罗河水位、巴比伦月食——先能**记下**长期序列，才能靠周期表外推 |
| 1662 | 死亡率预测（生命表）| 印刷的死亡登记 (Bills of Mortality) + 算术 | Graunt 把伦敦死亡名单**汇总成表**，第一张生命表 |
| 1682 | 彗星回归预测 | 牛顿力学 + 对数表 / 计算尺 | 哈雷靠手算轨道，预言 76 年后彗星回归 |
| 1801 | 轨道 / 位置预测 | 最小二乘 + 手算 | 高斯用少量观测反推谷神星轨道 |
| 1876 | 潮汐预测 | Kelvin 潮汐预测机（机械模拟计算机）| 用齿轮做谐波合成，**机器第一次"算"出**未来潮位 |

## 1900 — 1960s：从机械计算器到机载计算机

20 世纪上半叶的算力是**手摇 / 电动机械计算器**，二战带来**模拟与电子计算机**，到 60 年代出现了**集成电路与机载计算机**。这一阶段最深刻的教训是：**内存与算力的形状，直接决定了算法的形状**。

| 年代 | 任务 | 使能技术 / 产品 | 一句话：技术如何让任务成为可能 |
|------|------|----------------|------------------------------|
| 1900 | 股价建模 | 手算 + 概率论 | Bachelier 用随机游走描述巴黎国债价格 |
| 1927 | 经济 / 自然指标预测 | 手摇 · 电动机械计算器 | 机械计算器让回归求解可行，Yule 拟合 AR 预测太阳黑子 |
| 1940s | 信号 / 目标预测（军事）| 二战火控 · 模拟计算机 | 防空火控要从含噪轨迹外推目标位置 → Wiener–Kolmogorov 最优滤波 |
| 1950s | 库存 / 销售预测 | 早期电子计算机（昂贵、算力稀缺）| **算力贵**，催生 O(1) 递推的指数平滑，能低成本预测上万条 SKU |
| 1960 | 导航 / 定位跟踪 | 阿波罗制导计算机（集成电路、KB 级内存）| **内存极小 → 递推式**卡尔曼滤波正合适，实现登月实时定位 |

> 注意 1950s 与 1960s 这两行：指数平滑之所以胜出，是因为当时算力昂贵；卡尔曼滤波之所以是"预测—更新"的递推形式，是因为机载计算机只有几 KB 内存、存不下全部历史。**约束塑造了方法。**

## 1970s — 1990s：大型机、个人电脑与工业传感

70 年代的**大型机**让迭代式数值优化第一次跑得起；80 年代**个人电脑 / 工作站**把建模能力送进办公室与交易室；90 年代**工业传感器 + 数据采集 (SCADA) + 廉价存储**让"持续记录设备状态"成为常态。

| 年代 | 任务 | 使能技术 / 产品 | 一句话：技术如何让任务成为可能 |
|------|------|----------------|------------------------------|
| 1970 | 宏观经济预测 | 大型机（IBM System/360 等）| **迭代极大似然**第一次跑得动，Box–Jenkins ARIMA 成为范式 |
| 1970s | 语音识别 | DARPA 项目 + 大型机 | 算力够做 HMM + Viterbi 动态规划，转录电话语音 |
| 1973 | 期权定价 | 手持计算器 + 大型机 | Black–Scholes 公式 + 数值计算，催生交易所规模化定价 |
| 1980s | 风险管理 (VaR) | 个人电脑 / 工作站 + 计量软件 | PC 普及让 GARCH 波动率建模走进交易室 |
| 1987 | 多变量协整 | 工作站 + 统计软件 | Engle–Granger 做宏观变量长期均衡预测 |
| 1990s | 设备故障预测 | 工业传感器 + SCADA + 廉价存储 | **能持续采集并存下**传感器序列，才谈得上预测性维护 |
| 1997 | 长依赖序列建模 | 当时的 CPU（GPU 尚未登场）| LSTM 用门控解决梯度消失——但真正大放异彩要等到 GPU 时代 |

## 2000s — 2010s：互联网规模数据、集群与 GPU

这是算力的转折点：**互联网带来海量序列数据**，**服务器集群 + 数据仓库**让存储与并行计算变廉价，而 2007 年起 **NVIDIA GPU + CUDA** 把深度网络的训练成本压低了一个量级——2012 年 AlexNet 之后，深度序列模型随之爆发。

| 年代 | 任务 | 使能技术 / 产品 | 一句话：技术如何让任务成为可能 |
|------|------|----------------|------------------------------|
| 2012 | **深度学习起飞（转折点）**| NVIDIA GPU + CUDA（AlexNet）| GPU 通用计算让深度网络训练成本骤降，序列建模从此换挡 |
| 2017 | 全局概率预测 | 云 GPU（如 AWS）+ 大规模序列库 | DeepAR 跨成千上万条序列联合训练，输出概率分布 |
| 2017 | 异常检测 | 大规模监控 / 遥测基础设施 | 服务器、网络流量遥测 → Autoencoder/LSTM 实时告警 |
| 2019 | 可解释预测 | GPU 集群 | N-BEATS 纯前馈 + 残差堆叠，输出趋势/季节分解 |

## 2020s — 今天：加速卡集群与基础模型

当算力进入 **GPU / TPU 大规模集群 + 海量预训练**的时代，任务发生了质变：不再为每个问题单独训练模型，而是**预训练一个通用模型**去解尚未见过的任务。算力的过剩，反过来推动了任务的"通用化"。

| 年代 | 任务 | 使能技术 / 产品 | 一句话：技术如何让任务成为可能 |
|------|------|----------------|------------------------------|
| 2020s | 时间序列分类 | GPU | 心电图分类、工业振动信号故障诊断，Transformer / CNN |
| 2020s | 时间序列生成 | GPU + 扩散 / 生成模型框架 | 生成逼真的金融、医疗合成数据 |
| 2023– | 零样本预测 | 大规模预训练 + 加速卡集群 | TimesFM、Chronos 预训练一个模型，免训练预测新序列 |
| 2024– | 多模态 / 对话式时间序列 | LLM 推理基础设施 | 文本 + 图像 + 传感器联合，用自然语言问"下周销量？" |

## 算力如何"解锁"任务

> **不是方法在凭空进化，而是计算技术每抬高一级，就解锁了一批新任务。**

把上面五个时代串起来，能看到几条清晰的因果脉络：

1. **存储决定"能不能有序列"**：没有泥板、死亡登记、SCADA、数据仓库这样的记录手段，就没有数据可分析——故障预测、CTR 预测都要先等"存得下"。
2. **内存的形状决定算法的形状**：阿波罗机载计算机只有 KB 级内存，逼出了卡尔曼滤波"预测—更新"的递推结构；存不下全部历史，就只能在线更新。
3. **算力的价格决定方法的复杂度**：算力贵时，胜出的是 O(1) 的指数平滑；算力便宜后，复杂的深度网络才划算。
4. **新产品直接打开新任务**：潮汐预测机、大型机、个人电脑、GPU、TPU 集群——每一代标志性产品的出现，都对应着一批"以前算不动"的任务第一次变得可行。
5. **算力过剩推动"通用化"**：当预训练一个大模型的成本可以接受，任务就从"一题一模型"走向"一个模型通吃"（基础模型、零样本、多模态）。
