**偏差—方差权衡**说的是：一个模型的预测误差可以拆成两部分，**偏差**（模型假设太死板，系统性地偏离真相）和**方差**（模型对训练数据太敏感，换一批数据结论就大变）。模型越简单偏差越大，越复杂方差越大，我们要在两者之间找一个甜点。

## 直观理解

想象你在打靶。

- **高偏差、低方差**：每一枪都打得很集中，但整体偏离靶心。就像你用一把准星歪了的枪——再稳也打不准。对应**欠拟合**：模型太简单，连训练数据的规律都抓不住。
- **低偏差、高方差**：平均落点正好在靶心附近，但弹着点散得到处都是。就像手抖得厉害——偶尔中靶纯属运气。对应**[过拟合](../overfitting/)**：模型太复杂，把训练数据里的噪声也当成规律记住了。
- **低偏差、低方差**：又准又稳，这是我们想要的，但现实中通常只能逼近。

关键直觉：**偏差和方差往往此消彼长**。把模型变复杂能降低偏差，但同时会抬高方差；反之亦然。

## 数学表达

假设真实关系是 $y = f(x) + \varepsilon$，其中 $\varepsilon$ 是均值为 0、方差为 $\sigma^2$ 的噪声。我们用训练集学到一个模型 $\hat{f}(x)$。在某个固定的测试点 $x_0$ 上，对"所有可能的训练集"取期望，预测的均方误差可以精确分解为：

$$
\mathbb{E}\big[(y - \hat{f}(x_0))^2\big]
= \underbrace{\big(\mathbb{E}[\hat{f}(x_0)] - f(x_0)\big)^2}_{\text{偏差}^2}
+ \underbrace{\mathbb{E}\big[(\hat{f}(x_0) - \mathbb{E}[\hat{f}(x_0)])^2\big]}_{\text{方差}}
+ \underbrace{\sigma^2}_{\text{不可约误差}}
$$

逐项解释：

- **偏差$^2$**：$\mathbb{E}[\hat{f}(x_0)]$ 是模型预测的"平均值"（对不同训练集而言），它与真值 $f(x_0)$ 的差距。偏差大说明模型结构本身就不对。
- **方差**：模型预测围绕自己平均值的波动幅度。方差大说明换一批训练数据，预测就会剧烈变化。
- **不可约误差 $\sigma^2$**：数据里固有的随机噪声，**任何模型都消不掉**，它是误差的下限。

我们能控制的只有前两项，目标是让 **偏差$^2$ + 方差** 这个和最小——而不是单独把某一项压到极致。

## 一个具体例子

用多项式去拟合一条带噪声的曲线，体会复杂度如何影响两者：

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(0)
x = np.linspace(0, 1, 60).reshape(-1, 1)
y = np.sin(2 * np.pi * x).ravel() + rng.normal(0, 0.2, 60)
Xtr, Xte, ytr, yte = train_test_split(x, y, test_size=0.4, random_state=0)

for deg in [1, 4, 15]:
    model = make_pipeline(PolynomialFeatures(deg), LinearRegression())
    model.fit(Xtr, ytr)
    tr = np.mean((model.predict(Xtr) - ytr) ** 2)
    te = np.mean((model.predict(Xte) - yte) ** 2)
    print(f"次数={deg:2d}  训练MSE={tr:.3f}  测试MSE={te:.3f}")
```

典型输出会是这样的趋势：

- **次数=1**（直线）：训练和测试误差都偏大 → **高偏差**（欠拟合）。
- **次数=4**：训练和测试误差都较小且接近 → **平衡点**，最佳。
- **次数=15**：训练误差几乎为 0，但测试误差暴涨 → **高方差**（过拟合）。

## 为什么重要 / 用在哪

这个框架是理解**几乎所有调参选择**的统一视角：

- **调模型复杂度**：树的深度、神经网络层数、多项式次数——本质都是在偏差和方差间滑动。
- **[正则化](../regularization/)**：$\ell_2$ / $\ell_1$ 惩罚、早停、Dropout 都是在**主动增加一点偏差，换取方差的大幅下降**。
- **集成方法**：[Bagging / 随机森林](../ensemble-gbdt/)主要降方差（对多个高方差模型取平均）；Boosting 主要降偏差（逐步纠正残差）。
- **加数据**：更多训练数据主要降的是方差——它让模型对单个噪声点不那么敏感。

## 在时间序列预测中的意义

在预测任务里，这个权衡同样无处不在，但有几点特殊：

- **窗口长度 = 复杂度旋钮**：用很短的历史窗口预测，模型简单、偏差大、容易漏掉趋势/季节性；用很长的窗口加很多特征，方差大、容易把偶发波动当规律。
- **季节性建模**：只用上周同一天（单一滞后）偏差大；塞进几十个滞后特征又会高方差。常见做法是用**少量有意义的滞后 + 正则化**来折中。
- **评估必须按时间顺序**：判断你处在偏差区还是方差区，要靠 [时间序列交叉验证](../cross-validation/)（滚动/扩展窗口），**绝不能随机打乱**，否则会被"未来泄漏"骗得低估方差。

## 小结

- 误差 = 偏差$^2$ + 方差 + 不可约噪声；最后一项消不掉。
- **欠拟合 ↔ 高偏差**，**过拟合 ↔ 高方差**，两者通常此消彼长。
- 目标不是把某一项压到 0，而是让两者之和最小——这通常出现在中等复杂度处。
- 正则化、集成、加数据都是调节这一权衡的工具。
