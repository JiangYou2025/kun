## 4.1 概率与统计基础

预测本质上是在**不确定性**下做判断，概率是它的语言。

- **随机变量与分布**：把"下一个值"看成服从某个分布的随机变量
- **期望、方差、协方差**：刻画中心、波动与两个变量的联动
- **条件概率**：预测就是求 $P(x_{t+1} \mid x_{\le t})$
- **正态分布**：很多模型默认残差服从 $\mathcal{N}(0,\sigma^2)$
- **极大似然估计 (MLE)**：经典模型（如 ARIMA）的参数估计基础

## 4.2 线性代数基础

数据是向量，模型是矩阵运算。

- **向量与矩阵**：一个滑动窗口就是一个向量，一批样本就是一个矩阵
- **矩阵乘法**：神经网络每一层、线性回归 $\hat{y}=X\beta$ 都是矩阵乘法
- **范数**：$\ell_2$ 度量误差大小，$\ell_1$ 带来稀疏
- **特征值 / 分解**：PCA、协方差结构、稳定性分析的工具

## 4.3 微积分与优化

"训练模型" = "找到让损失最小的参数"。

$$\theta^\* = \arg\min_\theta \; \mathcal{L}(\theta)$$

- **导数与梯度**：损失对参数的偏导，指出下降方向
- **梯度下降**：$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}$，$\eta$ 是学习率
- **随机 / 小批量梯度下降 (SGD / mini-batch)**：用一小批样本估计梯度，是深度学习的主力
- **凸 vs 非凸**：经典模型常是凸的（有全局最优），神经网络是非凸的（只求好的局部最优）

## 4.4 监督学习范式

绝大多数预测模型都落在**监督学习**框架里：给定输入 $X$，学习映射到输出 $y$。

- **特征 $X$ 与标签 $y$**：时间序列里，输入常是过去窗口，标签是未来值
- **模型 = 一族函数 $f_\theta$**：训练就是在这族函数里挑参数
- **回归 vs 分类**：预测连续值（回归）还是离散类别（分类）
- **泛化**：目标不是记住训练数据，而是在**没见过**的数据上表现好

## 4.5 损失函数与训练 / 验证 / 测试

- **损失函数**：衡量预测与真实的差距，回归常用 MSE / MAE
- **数据切分**：训练集学参数、验证集调超参、测试集报性能
- **时间序列的特殊性**：**绝不能随机打乱切分**，必须按时间顺序切，避免用未来预测过去（数据泄漏）

```python
# 时间序列按顺序切分，不能 shuffle
n = len(series)
train = series[: int(n * 0.7)]
val   = series[int(n * 0.7) : int(n * 0.85)]
test  = series[int(n * 0.85) :]
```

## 4.6 过拟合、正则化与偏差—方差权衡

- **欠拟合**：模型太简单，训练集都学不好（高偏差）
- **过拟合**：模型太复杂，记住了噪声，测试集崩溃（高方差）
- **偏差—方差权衡**：复杂度增加 → 偏差降、方差升，要找平衡点
- **正则化**：$\ell_2$（岭）、$\ell_1$（套索）、早停、Dropout，都是给模型"加约束"以提升泛化

> 直觉：预测的目标不是把历史拟合得天衣无缝，而是**学到可外推的规律**。一个在训练集上误差为零的模型，往往是过拟合的危险信号。
