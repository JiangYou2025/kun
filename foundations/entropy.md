> 出自[数学基础](../math/) · [基础课总览](../)

熵衡量一个[随机变量](../random-variable/)的**不确定性**有多大：结果越难猜，熵越高；结果越确定，熵越低。它是[信息论](../information-theory/)的基石，也刻画了"一件事最少需要多少信息才能说清楚"。

## 直观理解

把熵想成"**平均要问多少个是非题才能猜中答案**"。

- 一枚**均匀硬币**，正反各 50%，你最少问 1 个问题（"是正面吗？"），熵 = 1 比特。
- 一枚**作弊硬币**，99% 出正面，你几乎不用问就知道答案，熵接近 0。
- 一个**16 面均匀骰子**，每面机会均等，最难猜，熵 = 4 比特。

规律：**越均匀、可能性越多 → 越不确定 → 熵越高**；越偏向某个结果 → 越确定 → 熵越低。熵在均匀分布时取得最大值。

## 数学表达

离散随机变量 $X$ 的香农熵：

$$
H(X)=-\sum_i p_i \log p_i
$$

- $p_i$ —— 事件 $i$ 的概率；
- 约定 $0\log 0 = 0$；
- $\log$ 底为 2 时单位是**比特（bit）**，底为 $e$ 时单位是 **nat**。

为什么是 $-\log p$？因为单个事件携带的"信息量"定义为 $-\log p_i$：**越罕见的事件发生，带来的信息越多**（"今天太阳照常升起"几乎没信息，"今天下雪了（在沙漠）"信息量巨大）。熵就是信息量按概率加权的**平均值**，即期望 $\mathbb{E}[-\log p]$。

## 一个具体例子

比较两枚硬币的熵（以 2 为底）：

均匀硬币 $p=[0.5,0.5]$：

$$
H=-(0.5\log_2 0.5+0.5\log_2 0.5)=-(0.5\cdot(-1)+0.5\cdot(-1))=1\ \text{比特}
$$

偏置硬币 $p=[0.9,0.1]$：

$$
H=-(0.9\log_2 0.9+0.1\log_2 0.1)\approx 0.469\ \text{比特}
$$

后者更确定，熵更小。

```python
import numpy as np
def entropy(p):
    p = np.array(p)
    p = p[p > 0]
    return -np.sum(p * np.log2(p))
print(round(entropy([0.5, 0.5]), 3))   # 1.0
print(round(entropy([0.9, 0.1]), 3))   # 0.469
```

## 为什么重要 / 用在哪

- **[决策树](../decision-tree/)**：用"信息增益"（划分前后熵的下降）来选最有区分力的特征。
- **[损失函数](../loss-function/)**：[交叉熵](../cross-entropy/)与 [KL 散度](../kl-divergence/)都建立在熵之上。
- **压缩理论**：熵给出无损压缩的理论下限——平均编码长度不可能短于熵。

## 在时间序列预测中的意义

- 熵直接刻画**预测难度**：一个高熵（接近随机游走、噪声大）的序列，无论模型多强，可预测性都有理论上限。
- 评估特征或历史窗口"有多少信息"时，熵给出量化工具。
- 训练 KUN（Kernel U-Net）若涉及概率/分类形式的输出，其损失（交叉熵）的下限正是真实分布的熵——你永远无法把损失压到比数据本身的不确定性更低。

## 小结

- 熵 = 平均不确定性 = 平均信息量 $\mathbb{E}[-\log p]$。
- 均匀分布熵最大，确定事件熵为 0。
- 它是交叉熵、KL 散度、信息增益、压缩极限的共同源头，也是预测难度的理论标尺。
