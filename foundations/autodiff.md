**自动微分（automatic differentiation, autodiff）**是框架（PyTorch、TensorFlow、JAX）自动、**精确**地计算任意计算图导数的技术。你只管写前向计算，框架就能算出[梯度](../gradient/)——你再也不用手推导数。[反向传播](../backpropagation/)正是它在[神经网络](../neural-network/)上的一个特例。

## 直观理解

任何复杂的计算，归根结底都是由一堆**基本运算**（加、乘、指数、矩阵乘……）拼起来的。而每个基本运算的导数我们都早就知道（$\frac{d}{dx}e^x = e^x$，乘法用乘法法则……）。

自动微分的核心想法很朴素：**既然每个小积木的导数已知，那就用[链式法则](../chain-rule/)把它们机械地拼起来**，整张图的导数自然就出来了。框架在你做前向计算时，悄悄把每一步运算记录成一张**计算图**；求梯度时，沿着这张图反向走一遍即可。

它不同于另外两种求导方式：

- **数值微分**：用 $\frac{f(x+h)-f(x)}{h}$ 近似——有**舍入误差**，且每个参数都要重算一次，慢得无法用于百万参数。
- **符号微分**：像数学课那样推出导数公式——表达式会**爆炸式膨胀**。
- **自动微分**：精确到机器精度，且复杂度可控。这正是它胜出的原因。

## 原理：两种模式

自动微分有两种走向：

**前向模式（forward mode）**：沿计算图正向，同时携带导数信息。适合"输入少、输出多"。

**反向模式（reverse mode）**：先正向算一遍并记录图，再**从输出反向**回传导数。适合"输入多、输出少"——而[深度学习](../dl/)恰好是"百万参数输入、一个标量损失输出"，所以框架都用反向模式。**反向传播就是反向模式自动微分。**

反向模式的核心仍是链式法则。对计算图中每个中间变量 $v$，框架维护伴随量（adjoint）

$$
\bar{v} = \frac{\partial \mathcal{L}}{\partial v}
$$

并按反向拓扑序传播：若 $v$ 影响了 $u_1, u_2, \dots$，则

$$
\bar{v} = \sum_{i} \bar{u}_i \, \frac{\partial u_i}{\partial v}
$$

符号解释：$\mathcal{L}$ 是最终标量输出（损失）；$\bar v$ 表示"$v$ 变一点，$\mathcal{L}$ 变多少"；$\frac{\partial u_i}{\partial v}$ 是单个基本运算的**局部导数**（已知）。一次反向扫描就填满所有 $\bar v$。

## 一个具体例子

求 $f(x) = x^2 \cdot \sin(x)$ 在 $x=2$ 处的导数。手算结果应是 $f'(x) = 2x\sin x + x^2\cos x$，代入 $x=2$：$4\sin2 + 4\cos2 \approx 4(0.909) + 4(-0.416) \approx 1.97$。

用 PyTorch 的自动微分：

```python
import torch
x = torch.tensor(2.0, requires_grad=True)   # 标记要追踪梯度
y = x**2 * torch.sin(x)                       # 前向：框架同时建好计算图
y.backward()                                  # 反向：自动求导
print(x.grad)                                 # tensor(1.9726) —— 与手算一致
```

我们**完全没写导数公式**，框架沿着 `pow`、`sin`、`mul` 这三个基本运算的局部导数自动拼出了结果。这就是 autodiff 的威力。

## 为什么重要 / 用在哪

- **它是深度学习框架的引擎**。你定义任意复杂的网络（循环、分支、注意力……），都能自动得到梯度，无需手推。
- **支持动态结构**。像 [RNN](../rnn/) 这类随输入长度变化的图，autodiff 照样处理。
- 它解放了研究者：发明新的层、新的[损失函数](../loss-function/)时，**不必担心怎么求导**——这极大加速了模型创新。
- 算出的梯度随即交给[优化器](../optimizer/)（如 [Adam](../adam/)）更新参数。

## 常见误区

- **"autodiff = 数值微分"**——不。autodiff **精确**（到机器精度），数值微分是近似。
- **"autodiff = 符号微分"**——不。它不生成庞大的导数公式，而是按图数值地传播导数。
- **"反向传播和 autodiff 是两回事"**——反向传播是 autodiff（反向模式）在神经网络上的具体应用，二者一脉相承。
