**线性模型**就是用输入特征的**线性组合**（加权求和再加一个偏置）来做预测。它简单、可解释、训练快，是几乎所有机器学习任务里最该先试的**基线模型（baseline）**。

## 直观理解

想象你要根据房子的面积来预测房价。最朴素的想法是：**每平米值多少钱，再加上一个起步价**。写成式子就是

$$\text{房价} \approx w \times \text{面积} + b$$

这里的 $w$（斜率）告诉你「面积每增加一平米，价格涨多少」，$b$（截距）是面积为 0 时的「基础价」。当你有多个特征（面积、楼层、离地铁距离……）时，就给每个特征配一个权重，把它们加起来——这就是线性模型的全部秘密：**一条直线（或高维里的一个平面）去拟合数据**。

它的「线性」不是说世界是线性的，而是说**模型对参数 $w$ 是线性的**。正因为结构这么简单，我们能清楚地看出每个特征到底起了多大作用，这种**可解释性**是很多复杂模型给不了的。

## 数学表达：线性回归

对一个有 $d$ 个特征的样本 $x = (x_1, x_2, \dots, x_d)$，线性回归的预测是

$$\hat{y} = w^\top x + b = \sum_{j=1}^{d} w_j x_j + b$$

- **权重 / 系数（coefficients）** $w_j$：第 $j$ 个特征对预测的「贡献率」。$w_j > 0$ 表示该特征越大、预测值越大；$w_j < 0$ 则相反；$w_j \approx 0$ 表示这个特征基本没用。
- **截距（intercept）** $b$：所有特征都为 0 时的基准预测。

怎么找到「最好」的 $w$ 和 $b$？我们让预测值 $\hat{y}_i$ 和真实值 $y_i$ 的差距尽量小，用**均方误差（MSE）**作为损失：

$$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}\left(y_i - \hat{y}_i\right)^2$$

最小化这个误差的方法叫**最小二乘法（least squares）**。神奇的是，它有**闭式解（closed-form solution）**——不用迭代，一步算出来：

$$w = (X^\top X)^{-1} X^\top y$$

其中 $X$ 是把所有样本按行堆起来的特征矩阵。这意味着线性回归训练极快，也是它能当「随手一试」基线的重要原因。

## 数学表达：逻辑回归（分类）

如果要做的是**分类**（比如「明天会不会下雨」），直接输出一个实数就不合适了，我们想要一个**概率**。于是把线性部分的输出再套一层 **Sigmoid 函数**，压缩到 $(0,1)$ 区间：

$$p = \sigma(w^\top x + b), \qquad \sigma(z) = \frac{1}{1 + e^{-z}}$$

$\sigma(z)$ 的图像是一条平滑的「S 形曲线」：$z$ 很大时趋近 1，很小时趋近 0，$z=0$ 时恰好是 0.5。$p > 0.5$ 就判为正类，否则判为负类。

逻辑回归不用 MSE，而是用**交叉熵（cross-entropy）**损失：

$$\mathcal{L} = -\frac{1}{n}\sum_{i=1}^{n}\Big[y_i \log p_i + (1-y_i)\log(1-p_i)\Big]$$

它衡量「预测的概率分布和真实标签差多远」，当模型把正类预测成高概率、负类预测成低概率时损失最小。

## 一个具体例子（sklearn）

```python
import numpy as np
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.preprocessing import StandardScaler

# ---- 线性回归：根据面积预测房价 ----
X = np.array([[50], [60], [80], [100], [120]])   # 面积
y = np.array([150, 180, 240, 300, 360])          # 价格（万）

reg = LinearRegression().fit(X, y)
print("斜率 w =", reg.coef_, "截距 b =", reg.intercept_)
print("预测 90㎡:", reg.predict([[90]]))

# ---- 逻辑回归：二分类，记得先标准化特征 ----
Xc = np.array([[1.0, 2.0], [2.0, 1.0], [3.0, 4.0], [4.0, 3.0]])
yc = np.array([0, 0, 1, 1])

scaler = StandardScaler()
Xc_scaled = scaler.fit_transform(Xc)             # 缩放后系数才可比
clf = LogisticRegression().fit(Xc_scaled, yc)
print("预测概率:", clf.predict_proba(scaler.transform([[2.5, 2.5]])))
```

注意这里特意做了**特征缩放（feature scaling）**：当不同特征的量纲差别很大（比如「面积」是几十、「房间数」是个位数）时，不缩放会让系数不可比，也会拖慢/扭曲优化。**标准化（StandardScaler）**几乎是线性模型的标配预处理。

## 为什么重要（用在哪）

- **强基线**：在动手上复杂模型之前，先跑一个线性模型。如果它已经够好，就没必要折腾；如果不够好，它也给了你一个「至少要超过它」的参考线。
- **快**：闭式解或简单的梯度下降，秒级训练，适合快速实验。
- **可解释**：看系数就知道哪个特征重要、方向如何，方便向别人解释、也方便排查数据问题。
- 当特征很多、容易过拟合时，它天然能和[正则化](../regularization/)配合，演化成 **Ridge（L2）** 和 **Lasso（L1）**，自动收缩甚至剔除无用特征。

## 在时间序列预测中的意义

时间序列预测里，线性模型的威力常被低估。核心技巧是构造**滞后特征（lag features）**：用过去几期的值 $y_{t-1}, y_{t-2}, \dots, y_{t-p}$ 当作输入特征，去预测当前 $y_t$。这时线性回归就变成了

$$\hat{y}_t = w_1 y_{t-1} + w_2 y_{t-2} + \dots + w_p y_{t-p} + b$$

这**本质上就是 AR（线性自回归）模型**！换句话说，经典时间序列里的自回归，就是「滞后特征上的线性回归」。它带来三个好处：

- 是一个**极强的预测基线**，很多花哨的深度模型其实未必能稳定打败它；
- **系数直接告诉你哪些滞后期重要**——比如 $w_1$ 很大说明强烈依赖上一期，$w_7$ 很大可能意味着以周为周期；
- 当滞后阶数 $p$ 取得很大、特征很多时，配合[正则化](../regularization/)（Lasso 会自动选出关键的几个滞后）能有效防止过拟合。

如果线性假设不够，再考虑[决策树](../decision-tree/)、[集成学习 / GBDT](../ensemble-gbdt/) 或核方法等更灵活的[模型族](../model-families/)。

## 小结

- **线性模型 = 特征的加权求和 + 偏置**：$\hat{y} = w^\top x + b$，结构最简单、最可解释。
- **线性回归**用 MSE / 最小二乘拟合，有闭式解 $w=(X^\top X)^{-1}X^\top y$；**逻辑回归**用 Sigmoid 输出概率、交叉熵训练，用于分类。
- 系数 $w_j$ 直接反映特征的重要性和方向；务必先做**特征缩放**让系数可比。
- 特征多时配合[正则化](../regularization/) → Ridge / Lasso。
- 时间序列里，**滞后特征上的线性回归 ≈ 线性自回归（AR）**，是又快又强的基线，系数还能告诉你哪些滞后期最关键。
