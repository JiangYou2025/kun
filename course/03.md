## 3.1 为什么从线性模型开始

预测听起来很玄，但最朴素的想法只有一句话：**未来是过去的某种线性组合**。线性模型简单、能手算、可解释，而且——这是最容易被低估的一点——**在很多真实基准上，一个线性层就能打平甚至打败复杂得多的深度模型**（第 10、11 讲会再回到这个惊人的事实）。所以我们把它当作一切的起点和"必须打败的基线"。

这一讲只用例子和最基本的公式，带你把"拟合 → 预测 → 看结果"这条主线走通。

## 3.2 用一条直线拟合趋势

最简单的模型：假设值随时间线性增长。把时间 $t$ 当自变量，

$$\hat{x}_t = a + b\,t.$$

$a$ 是截距（起点），$b$ 是斜率（每过一步涨多少）。**拟合 (fitting)** 就是从历史数据里找出最合适的 $a, b$；**预测 (forecasting)** 就是把未来的 $t$ 代进这条直线。

举例：某店日销量大致每天涨 2 件、起点 100 件，那么 $\hat{x}_t = 100 + 2t$，第 30 天预测就是 $100 + 2\times 30 = 160$ 件。

## 3.3 怎么算“最合适”：最小二乘

什么叫"最合适的直线"？我们让**预测和真实值的总误差最小**。用平方误差衡量：

$$\min_{a,b}\ \sum_{t=1}^{T} \big(x_t - (a + b\,t)\big)^2.$$

这就是**最小二乘 (least squares)**。它有闭式解（可直接套公式，不用迭代）：

$$b = \frac{\sum_t (t-\bar{t})(x_t-\bar{x})}{\sum_t (t-\bar{t})^2}, \qquad a = \bar{x} - b\,\bar{t}.$$

其中 $\bar t, \bar x$ 是时间和值的均值。**这套"定义损失 → 求最小"的思路，是后面所有模型（包括神经网络）的共同骨架**，只是模型变复杂、求解变成梯度下降而已。

## 3.4 用过去预测未来：自回归视角

直接用时间 $t$ 做自变量太粗糙——它假设永远匀速增长。更贴合时间序列的想法是：**用前几步的值预测下一步**。这就是**自回归 (AutoRegression, AR)**：

$$\hat{x}_t = c + \phi_1 x_{t-1} + \phi_2 x_{t-2} + \cdots + \phi_p x_{t-p}.$$

它仍然是个线性模型——只不过自变量从"时间"换成了"过去的观测值"。系数 $\phi_i$ 同样用最小二乘求解。直觉上：$\phi_1$ 大说明"昨天和今天高度相关"，序列有很强的惯性。第 8 讲会把它扩展成完整的 ARIMA。

## 3.5 一步预测与多步预测

模型一次只预测下一步，那预测未来 10 步怎么办？两种做法：

- **递归 (recursive)**：预测出 $\hat{x}_{t}$，把它当作真值再预测 $\hat{x}_{t+1}$，依次滚动。简单，但误差会累积。
- **直接 (direct)**：为每个步长单独训一个模型，分别预测第 1 步、第 2 步……更稳，但要训多个模型。

理解这个区别很重要：**一步准不代表多步准**，预测越远越不确定。

## 3.6 完整流程：一个最小例子

把前面拼起来，就是一次完整的预测：

1. **切数据**（第 2 讲）：用 $x_1\ldots x_{t_1}$ 当训练集。
2. **拟合**：在训练集上最小二乘求出 $a,b$（或 AR 的 $\phi$）。
3. **预测**：对测试段的时间 / 历史，算出 $\hat{x}_t$。
4. **看结果**（第 4 讲）：把预测和真实画在一起，算误差。

```python
import numpy as np
t = np.arange(len(train))
b, a = np.polyfit(t, train, deg=1)        # 最小二乘拟合直线
future = np.arange(len(train), len(train)+H)
pred = a + b * future                      # 外推预测未来 H 步
```

## 3.7 线性模型的边界

线性模型讲究"诚实地简单"，但要知道它学不到什么：

- **非线性**：阈值、饱和、突变它抓不住。
- **乘法型季节**：振幅随水平放大时，需要先做 log 变换（第 12 讲）。
- **多变量耦合**：变量间复杂的相互作用要交给后面的机器学习与深度模型。

但请记住：**任何复杂模型，都要先证明自己比这条线更好**，否则复杂就是白费。
