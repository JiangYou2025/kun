## 3.1 时序图与滚动统计

最基本的一步：**把数据画出来**。

- **时序图 (line plot)**：横轴时间，纵轴值 — 一眼看到趋势、季节性、突变
- **滚动均值/滚动标准差**：用窗口（如 7 天、30 天）滑动计算 — 看趋势是否在变、波动是否在增

```python
df['value'].plot()
df['value'].rolling(30).mean().plot()
```

## 3.2 分布与季节性子图

- **直方图 / 箱线图**：看值的分布是否对称、有没有重尾
- **按月/按周分组的箱线图**：揭示季节性模式
  - 电力数据：夏天和冬天用电高
  - 零售数据：12 月销量暴涨

## 3.3 滞后图与散点

**滞后图 (lag plot)**：把 $x_t$ 和 $x_{t-k}$ 画成散点图。如果看到明显的线性关系，说明序列有强自相关。

- lag=1 的散点图近似一条线 → 序列"记得"前一步
- lag=12 的散点图近似一条线 → 序列有年周期

## 3.4 多变量之间的关系

当有多个变量时：
- **相关矩阵热力图**：快速看哪些变量同步变化
- **交叉相关函数**：看一个变量是否**领先**另一个变量若干步

## 3.5 一份 EDA 检查清单

拿到一条新序列，先快速过一遍：

1. **趋势**：整体在涨还是跌？是线性还是加速？
2. **季节性**：有没有固定周期（日 / 周 / 年）？用季节子图确认。
3. **方差**：波动幅度是否随时间（或随水平）变化？→ 可能需要对数变换。
4. **异常与缺失**：有没有跳变、断档、明显离群点？
5. **结构突变**：是否存在事件造成的"换挡"（如疫情前后）？

这一步的产出会直接决定后面怎么分解、怎么变换、用什么模型。

---

**关键术语 (Key terms):** 时序图 (line plot)、滚动统计 (rolling statistics)、滞后图 (lag plot)、季节子图 (seasonal subseries plot)、交叉相关 (cross-correlation)。
