## 6.1 为什么要在意平稳性

设想你想"用历史规律预测未来"。可如果这个规律本身一直在变——均值在漂、方差在涨——那"从过去学到的"就没法套到未来。**平稳性 (stationarity)** 描述的正是"规律不随时间变"这件事。ARIMA 等经典模型之所以好用，前提就是输入平稳；所以在用它们之前，我们要先**检验**序列平不平稳，再想办法把它**变平稳**。

## 6.2 平稳性的定义

直观地说，**平稳序列**的统计性质不随时间改变。弱平稳（实务中常用的版本）要求三条：

$$\mathbb{E}[x_t] = \mu\ (\text{常数}), \qquad \text{Var}(x_t) = \sigma^2\ (\text{常数}), \qquad \text{Cov}(x_t, x_{t-k}) = \gamma(k)\ (\text{只依赖 } k).$$

也就是：**均值恒定、方差恒定、自相关只取决于时间间隔 $k$ 而非具体时刻**。大多数真实序列都不满足——有趋势（均值在动）、有季节（自相关随时刻变）、方差也常在变。

## 6.3 怎么判断：单位根检验

光凭眼睛容易看错，用统计检验更可靠：

- **ADF 检验 (Augmented Dickey-Fuller)**：原假设"有单位根（不平稳）"。**p < 0.05 → 拒绝原假设 → 平稳**。
- **KPSS 检验**：原假设反过来是"平稳"。和 ADF 互为补充，两个一起看更稳。

```python
from statsmodels.tsa.stattools import adfuller
print(adfuller(series)[1])   # p-value < 0.05 → 平稳
```

## 6.4 差分：去掉趋势

把序列变平稳，最常用的手段是**差分 (differencing)**——相邻两步相减：

$$\nabla x_t = x_t - x_{t-1}.$$

一阶差分能去掉线性趋势；对季节性，用**季节差分**：

$$\nabla_m x_t = x_t - x_{t-m},$$

其中 $m$ 是周期（如月度数据的年周期 $m=12$）。ARIMA(p, **d**, q) 里的 **d** 就是差分次数，通常 $d=1$ 或 $2$ 就够。

## 6.5 变换：稳定方差

当**方差随水平增大**（值大的地方波动也大，乘法型季节）时，差分解决不了，要先做变换：

$$\text{对数：}\ y_t = \log x_t, \qquad \text{Box-Cox：}\ y_t = \frac{x_t^{\lambda} - 1}{\lambda}.$$

它们能**压缩大值、拉平方差**，让乘法结构变成加法。金融、社交媒体这类"重尾、量级跨好几个数量级"的数据尤其需要——第 12 讲会专门展开。

## 6.6 别忘了：标准化与反变换

- 深度模型还常做**标准化**（Z-score / Min-Max），统计量只能用训练集算（第 2 讲，防数据泄漏）。
- 所有变换（log / Box-Cox / 差分 / 标准化）都必须**可逆**：预测在变换空间里做，最后要**反变换回原始尺度**才能用。

## 6.7 实践要点

- **为什么非要平稳**：ARIMA 的参数假设不随时间变；序列不平稳，估出来的参数就"过期"了。
- **别过度差分**：差太多次会引入人为的负自相关、放大噪声。先看自相关图（第 7 讲）和单位根检验，能 $d=1$ 解决就别上 $d=2$。
- **顺序**：一般先变换稳方差，再差分去趋势 / 去季节。
