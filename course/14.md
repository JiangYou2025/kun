## 14.1 N-BEATS

**Neural Basis Expansion Analysis (2019)**：纯前馈网络 + 残差堆叠。

- 每个 block 输出"回看"（拟合已知）和"预测"（推断未知）
- 多个 block 堆叠，每个 block 处理前一个的残差
- 可解释版本：强制 block 输出趋势和季节性基函数

## 14.2 为什么需要多尺度

真实时间序列同时包含多个尺度的模式：
- **短期**：小时级波动
- **中期**：周/月趋势
- **长期**：年度季节性

单一尺度的模型（无论是线性还是 Transformer）很难同时捕获所有尺度。

## 14.3 Kernel U-Net (KUN)

KUN 的核心思想：**像 U-Net 处理图像一样处理时间序列**。

1. **编码器**：逐步降采样，把长序列压缩成短的潜在表示 — 捕获越来越粗的尺度
2. **解码器**：逐步上采样，恢复到原始长度 — 从粗到细地重建
3. **跳跃连接**：编码器的每一层连接到解码器对应层 — 保留细节
4. **可插拔核**：每一步的降/升采样操作可以是线性、MLP、注意力 — 灵活适配

$$\text{encoder: } (T, C) \xrightarrow{\text{chunk}} (T/k_1, C') \xrightarrow{\text{chunk}} \cdots \xrightarrow{} (1, C_{\text{latent}})$$

$$\text{decoder: } (1, C_{\text{latent}}) \xrightarrow{\text{expand}} \cdots \xrightarrow{} (T, C)$$

## 14.4 KUN 的优势

| 特性 | DLinear | Transformer | KUN |
|------|---------|-------------|-----|
| 多尺度 | ✗ | 部分（patch） | ✓ 天然层次 |
| 可解释 | 趋势+季节 | 注意力图 | 每层对应一个尺度 |
| 灵活核 | 线性 | 注意力 | 线性/MLP/注意力可选 |
| 复杂度 | O(T) | O(T²) | O(T)（线性核） |
| 跳跃连接 | ✗ | ✗ | ✓ 保留细节 |
