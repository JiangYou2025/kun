## 15.1 概率预测

现实中，一个"点预测"远远不够——决策需要知道**不确定性**。

- **预测区间**：上下界（如 90% 置信区间）
- **分位数预测**：预测第 10%、50%、90% 分位数
- **概率分布**：输出完整的参数化分布（高斯、负二项等）

DeepAR、N-BEATS、Chronos 等模型都支持概率预测。

**怎么评估概率预测？** 点预测的 MAE / RMSE 不够用了，常用：

- **Pinball / 分位数损失**：对每个分位数的非对称惩罚，也是分位数回归的训练目标。
- **CRPS（连续分级概率评分）**：衡量预测的整个分布与真实值的契合度，是概率预测的"通用 RMSE"。

## 15.2 多变量预测策略

| 策略 | 做法 | 优缺点 |
|------|------|--------|
| **Channel-Independent** | 每个变量独立预测 | 简单、不捕获变量间关系 |
| **Channel-Mixing** | 所有变量一起输入 | 能学交叉关系，但维度高 |
| **图网络** | 用 GNN 建模变量间的关系图 | 灵活，但需要定义图结构 |

PatchTST 用 Channel-Independent 就很强，说明**不是所有情况都需要混合通道**。

## 15.3 基础模型与零样本预测

继 NLP 的大模型之后，2023 年起时间序列也迎来了**基础模型 (foundation models)**——在海量序列上预训练、追求"零样本预测"的通用模型，2024–2026 年迭代极快：

- **TimesFM** (Google)：在 Google Trends、维基访问量 + 合成数据上预训练；2025 年迭代到 2.x，支持更长上下文
- **Chronos** (Amazon)：把数值 token 化，套用语言模型架构；后续的 **Chronos-Bolt** 把推理速度提升约一个数量级
- **Moirai** (Salesforce)：多频率、多领域的通用预测；**Moirai-MoE** 用混合专家进一步扩容
- **Time-MoE / TabPFN-TS** (2025)：十亿参数级的稀疏专家模型，以及把表格基础模型迁移到时序的新思路

这些模型可以**零样本预测**——不在目标数据上训练就能给出预测，把"预训练 + 通用大模型"的范式带进了时间序列。但正如 [2026 前沿问题（见 KUN 页）](../../zh/kun/) 所说，时序分布的多样性远超文本，通用性仍是开放问题。

## 15.4 实战流程

一个完整的时间序列预测项目：

```
1. 理解业务问题 → 预测什么？预测多远？
2. 数据获取 → 频率、长度、缺失情况
3. 探索性分析 → 趋势、季节性、异常
4. 基线模型 → Naive、SES、ARIMA → 设定下限
5. 特征工程 / 深度学习 → 尝试多种方法
6. 评估 → 时间切分回测、多指标（MAE/MASE/CRPS）
7. 部署 → API 服务、自动重训、监控漂移
```

## 15.5 课程总结

| 方法族 | 代表 | 适合场景 |
|--------|------|---------|
| 经典统计 | ARIMA, ETS | 单变量、短序列、可解释性高 |
| 机器学习 | LightGBM, XGBoost | 丰富特征、中等规模 |
| 循环网络 | LSTM, GRU | 端到端、中等长度 |
| Transformer | PatchTST, iTransformer | 长序列、多变量 |
| U-Net | **KUN** | 多尺度、灵活核、高效 |
| 基础模型 | TimesFM, Chronos | 零样本、通用 |

> 没有最好的模型，只有最适合当前数据和约束的模型。先跑基线，再加复杂度。
