## 7.1 误差指标 (MAE / RMSE / MAPE / sMAPE)

指标定义了对*你的*问题来说“好”到底意味着什么。

| 指标 | 公式 | 何时使用 |
|---|---|---|
| **MAE** | $$\frac{1}{H}\sum\lvert x_t-\hat{x}_t\rvert$$ | 想要原始单位的误差，且对离群点鲁棒 |
| **RMSE** | $$\sqrt{\frac{1}{H}\sum (x_t-\hat{x}_t)^2}$$ | 希望对大误差惩罚更重 |
| **MAPE** | $$\frac{100}{H}\sum\frac{\lvert x_t-\hat{x}_t\rvert}{\lvert x_t\rvert}$$ | 需要无量纲的百分比（避免接近 0 的值）|
| **sMAPE** | 对称版 MAPE，分母用 $$(\lvert x_t\rvert+\lvert\hat{x}_t\rvert)/2$$ | 缓解 MAPE 对小分母的过度敏感 |

## 7.2 按时间切分 (Time-based train/val/test split)

时间序列**绝不能随机打乱**来切分——那会让未来的信息泄漏进训练。永远**按时间顺序**切：较早的一段训练，紧接着的一段验证，最近的一段测试。

```
|--- 训练 ---|-- 验证 --|-- 测试 --|
   过去 ───────────────────────► 现在
```

## 7.3 滚动与扩展窗口回测 (Rolling & expanding-window backtesting)

只切一刀只能得到一个碰运气的数字。**回测**模拟模型真实的使用方式：训练到某个时间点，预测下一段，向前滑动，重复，从而得到误差的**分布**而非单点。

```
|------ 训练 ------|-- 测试 --|
|--------- 训练 ---------|-- 测试 --|
|------------ 训练 ------------|-- 测试 --|
```

- **扩展窗口：** 训练集不断变长（上图）。
- **滚动窗口：** 训练集长度固定、整段向前滑动——更贴近“只用最近一段历史”的场景。

## 7.4 与基线对比 (Comparing against baselines)

任何指标都要**和[基线](../08/)并排报告**，不要孤立地看。“测试集 MAE = 3.2”本身没有意义；“比季节性朴素法低 18%”才说明你的模型真的有用。

## 7.5 数据泄漏的陷阱 (Data leakage pitfalls)

**数据泄漏**——让未来的信息以任何方式进入输入——是预测里最常见、也最隐蔽的 bug：离线指标好得离谱，一上线就崩。常见来源：

- 随机切分（而非按时间切分）。
- 用了**含未来的全量数据**去算归一化统计量、特征或缺失值填补。
- 目标穿越：特征里混进了预测时刻当期或更晚才能拿到的信息。

口诀：**任何统计量都只用训练段来估计，再应用到验证 / 测试段。**
