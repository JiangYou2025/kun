## 10.1 简单指数平滑 (SES)

$$\hat{x}_{t+1} = \alpha x_t + (1-\alpha) \hat{x}_t$$

只有一个参数 $\alpha \in (0,1)$：越大越重视最近的值，越小越平滑。

SES 适合**没有趋势、没有季节性**的序列。它等价于 ARIMA(0,1,1)。

## 10.2 Holt 线性趋势法

在 SES 基础上加一个**趋势项**：

- 水平方程：$\ell_t = \alpha x_t + (1-\alpha)(\ell_{t-1} + b_{t-1})$
- 趋势方程：$b_t = \beta(\ell_t - \ell_{t-1}) + (1-\beta) b_{t-1}$
- 预测：$\hat{x}_{t+h} = \ell_t + h \cdot b_t$

两个参数：$\alpha$ 控制水平，$\beta$ 控制趋势。

## 10.3 Holt-Winters 季节性方法

再加一个**季节项** $s_t$，得到完整的 Holt-Winters：

- **加法版**：$\hat{x}_{t+h} = \ell_t + h b_t + s_{t-m+h}$
- **乘法版**：$\hat{x}_{t+h} = (\ell_t + h b_t) \times s_{t-m+h}$

三个参数 $(\alpha, \beta, \gamma)$，适合**有趋势 + 有季节性**的序列。

## 10.4 ETS 框架

ETS = Error + Trend + Seasonal，系统性地组合三种成分的加法/乘法版本：

| 成分 | 选项 |
|------|------|
| Error | A (加法) 或 M (乘法) |
| Trend | N (无) / A (加法) / Ad (阻尼) |
| Seasonal | N (无) / A (加法) / M (乘法) |

共 30 种组合。`statsforecast` 或 `statsmodels` 可自动选择最优组合。

## 10.5 指数平滑 vs ARIMA

| | 指数平滑 | ARIMA |
|-|---------|-------|
| 思路 | 加权平均过去的值 | 线性组合过去的值和误差 |
| 参数 | 直觉：平滑系数 | 需要识别 p/d/q |
| 速度 | 非常快 (O(T)) | 较快 |
| 等价 | SES = ARIMA(0,1,1) | — |

两者是互补而非替代关系。实战中两种都试，取好的那个。
