## 11.1 滑动窗口：把序列变成表格

核心思想：用过去 $w$ 步作为输入特征，预测未来 $h$ 步。

```
[x1, x2, x3, x4, x5] → x6      (w=5, h=1)
[x2, x3, x4, x5, x6] → x7
...
```

这样时间序列就变成了一个标准的**表格回归问题**，可以用任何 ML 模型。

## 11.2 常用特征

除了原始滞后值，还可以构造：

| 特征类型 | 例子 |
|---------|------|
| 滞后值 | $x_{t-1}, x_{t-7}, x_{t-30}$ |
| 滚动统计 | 7日均值、30日标准差、最大值 |
| 时间特征 | 星期几、月份、小时、是否节假日 |
| 差分特征 | $x_t - x_{t-1}$、$x_t - x_{t-7}$ |
| 频域特征 | 主频率、频谱能量 |

## 11.3 LightGBM / XGBoost

梯度提升树 (GBDT) 是表格数据的王者：
- 不需要归一化
- 自动处理非线性
- 训练快、效果好
- 可解释（特征重要性）

```python
import lightgbm as lgb
model = lgb.LGBMRegressor(n_estimators=500)
model.fit(X_train, y_train)
```

## 11.4 SVR

支持向量回归：在高维空间中找最优超平面。适合小数据、高维特征的场景。核函数（RBF、多项式）引入非线性。

## 11.5 ML 方法的局限

- 特征工程**依赖领域知识**——特征选得好，模型就好
- 预测长度固定于训练时的窗口大小
- 不自然地处理多步预测（需要递归或直接多输出）
- 无法像 RNN/Transformer 那样**端到端学习时间依赖**

## 11.6 多步预测的两种做法

ML 模型天生只输出一个值，要预测 $H$ 步有两条路：

- **递归 (recursive)**：预测一步，把它当作真实值喂回去再预测下一步。简单，但误差会**逐步累积**。
- **直接 (direct)**：为每个步长各训一个模型（或一个多输出模型）。无累积误差，但要训多个模型、且忽略了步间关联。

## 11.7 验证：别用普通 K 折

表格化之后它仍然是**时间序列**——交叉验证要用 `TimeSeriesSplit`（按时间向前滚动），绝不能随机 K 折，否则又会数据泄漏。构造滚动特征时也只能用"截至当前时刻"的信息。
