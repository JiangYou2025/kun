## 4.1 趋势、季节性、周期与噪声

一条时间序列可以被看成几种成分的叠加：

- **趋势 (Trend)**：长期上升或下降的方向
- **季节性 (Seasonality)**：固定周期的重复模式（每周、每年）
- **周期 (Cycle)**：不固定周期的波动（经济周期）
- **噪声 (Noise)**：随机波动，无法预测

## 4.2 加法分解与乘法分解

$$x_t = T_t + S_t + R_t \quad \text{(加法)}$$

$$x_t = T_t \times S_t \times R_t \quad \text{(乘法)}$$

- **加法**：季节波动的幅度不随趋势变化（振幅恒定）
- **乘法**：季节波动随趋势放大（值大→波动大）

## 4.3 移动平均与 STL 分解

- **移动平均分解**：用窗口均值提取趋势，残差中提取季节性
- **STL (Seasonal-Trend decomposition using LOESS)**：更灵活的分解方法，允许季节成分随时间变化

```python
from statsmodels.tsa.seasonal import STL
stl = STL(series, period=12)
result = stl.fit()
result.plot()
```

## 4.4 去趋势与去季节

为什么要分解？因为很多经典模型假设数据是**平稳的**（没有趋势和季节性）。分解后：
- 去掉趋势 → 差分或回归
- 去掉季节 → 季节性差分或减去季节均值
- 剩下的"去趋去季残差"才是模型真正要学的东西
