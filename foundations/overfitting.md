> 出自[机器学习基础](../ml/) · [基础课总览](../)

**过拟合**指模型在训练数据上表现极好，却把数据里的**噪声和偶然巧合**也当成了真规律，结果在没见过的新数据上反而很差。它是[机器学习](../ml/)中最常见的失败模式，与之相对的是**欠拟合**（模型太简单，连训练数据都学不好）。

## 直观理解

想象一个学生备考：

- **欠拟合的学生**：根本没怎么学，基础题和考试题都不会做。
- **过拟合的学生**：把往年真题的**答案**一字不差地背了下来——只要题目一改数字就懵了。他记住的是具体答案，而不是解题方法。
- **[泛化](../generalization/)好的学生**：理解了背后的方法，遇到新题也能做对。

过拟合的本质就是"死记硬背"：模型容量足够大，于是它选择了**记住每个训练样本**这条捷径，而不是去**总结可推广的规律**。

## 怎么识别它

最可靠的信号是**训练误差和验证误差的差距（gap）**：

$$
\text{泛化差距} = \text{验证误差} - \text{训练误差}
$$

- 训练误差低、验证误差也低且接近 → 拟合良好。
- 训练误差**很低**、验证误差**明显更高** → **过拟合**，gap 大。
- 训练误差和验证误差**都高** → 欠拟合。

在训练[神经网络](../neural-network/)时，画一条**学习曲线**（横轴 epoch，纵轴损失）：如果训练[损失](../loss-function/)持续下降而验证损失开始**回升**，那个拐点就是过拟合的起点——也是[早停](../regularization/)该出手的地方。

## 为什么会发生

从[偏差—方差](../bias-variance/)视角看，过拟合 = **高方差**。常见诱因：

- **模型容量相对数据太大**：参数比样本还多（高次多项式、超深的树、超大网络）。
- **训练数据太少或噪声大**：样本不够，模型只能去拟合个别点。
- **特征里有泄漏或冗余**：模型抓住了某个偶然相关但无因果的特征。
- **训练太久**：迭代过多，模型从学规律滑向背样本。

## 一个具体例子

```python
import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(1)
X = rng.uniform(0, 1, (120, 1))
y = (np.sin(6 * X).ravel() + rng.normal(0, 0.15, 120))
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.4, random_state=0)

for depth in [2, 5, None]:   # None = 不限深度，可任意分裂
    m = DecisionTreeRegressor(max_depth=depth, random_state=0).fit(Xtr, ytr)
    tr = np.mean((m.predict(Xtr) - ytr) ** 2)
    te = np.mean((m.predict(Xte) - yte) ** 2)
    print(f"max_depth={str(depth):>4}  训练MSE={tr:.3f}  测试MSE={te:.3f}")
```

不限深度的树训练 MSE 会接近 0（它能给每个样本单独开一个叶子），但测试 MSE 反而最大——这就是过拟合的教科书现象。

## 怎么对付它

- **加更多数据 / 数据增强**：最根本的办法。
- **[正则化](../regularization/)**：$\ell_1$ / $\ell_2$ 惩罚、[Dropout](../dropout/)、给树剪枝、限制 `max_depth`。
- **早停**：在验证损失开始回升时停止训练。
- **降低模型复杂度**：更少特征、更浅的模型。
- **[交叉验证](../cross-validation/)选超参**：用验证集而不是训练集来挑模型。
- **[集成](../ensemble-gbdt/)**：Bagging / 随机森林通过平均来压低方差。

## 在时间序列预测中的意义

时间序列里的过拟合尤其隐蔽，因为数据点之间**不独立**：

- **未来泄漏（look-ahead bias）**：用了预测时刻还拿不到的信息（比如未来的统计量、随机打乱后的验证集），会让验证分数虚高——这是一种"作弊式过拟合"。务必用 [时间序列交叉验证](../cross-validation/) 按时间切分。
- **滞后特征过多**：塞进几十上百个滞后/滚动统计特征，模型很容易记住历史的偶然波动。优先选少量有业务含义的特征 + 正则化。
- **对单一历史片段过拟合**：某段历史的特殊事件（疫情、促销）会被当成常态。用滚动窗口在**多个时间段**上验证更稳。

## 小结

- 过拟合 = 训练好、测试差，对应**高方差**、死记硬背。
- 用**训练/验证误差的 gap** 和**学习曲线**来诊断。
- 武器库：更多数据、正则化、早停、降复杂度、交叉验证、集成。
- 在预测里，最危险的是**未来泄漏**——按时间切分是底线。
