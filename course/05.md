## 5.1 平稳性的定义

**平稳序列 (stationary)**：统计性质不随时间改变 — 均值恒定、方差恒定、自相关只取决于时间差。

大多数真实序列**不平稳**（有趋势、有季节性、方差在变）。但 ARIMA 等经典方法要求平稳输入，所以需要先做变换。

## 5.2 单位根检验

如何判断序列是否平稳？

- **ADF 检验 (Augmented Dickey-Fuller)**：检验是否有单位根。p-value < 0.05 → 平稳
- **KPSS 检验**：反过来，检验是否平稳。两种检验互为补充

```python
from statsmodels.tsa.stattools import adfuller
result = adfuller(series)
print(f'p-value: {result[1]}')  # < 0.05 → 平稳
```

## 5.3 差分与季节性差分

**差分 (differencing)**：$y_t = x_t - x_{t-1}$。去掉线性趋势。

**季节性差分**：$y_t = x_t - x_{t-m}$，其中 $m$ 是周期（如 12 代表月度数据的年周期）。

ARIMA(p,d,q) 里的 **d** 就是差分次数。通常 d=1 或 d=2 就够了。

## 5.4 对数与 Box-Cox 变换

当方差随均值增大而增大时（乘法型季节性），先取对数或做 Box-Cox 变换：

$$y_t = \frac{x_t^\lambda - 1}{\lambda}$$

这会**稳定方差**，让序列更接近加法模型。

## 5.5 归一化与标准化

深度学习模型通常需要归一化输入：
- **Min-Max**：缩放到 [0, 1]
- **Z-score**：减均值除标准差
- **注意**：用训练集的统计量，不要用测试集的（数据泄漏）
