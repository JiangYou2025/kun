**循环神经网络（RNN, Recurrent Neural Network）** 是一种按时间步逐个读入序列、并用一个"隐藏状态"把过去信息一直带到现在的网络。它天生适合处理有先后顺序的数据，比如文字、语音和时间序列。

## 直观理解

想象你在读一句话："今天天气很……"。读到这里，你脑子里已经攒下了一点"语境"，于是你能猜下一个字大概是"好"或"热"。你不是把每个字孤立地看，而是**一边读、一边更新脑中的记忆**，这个记忆又影响你对下一个字的理解。

RNN 做的就是这件事。它有一个叫**隐藏状态**（hidden state）$h_t$ 的"记忆向量"：

- 每来一个新输入 $x_t$，它就把 $x_t$ 和上一刻的记忆 $h_{t-1}$ 揉在一起，算出新的记忆 $h_t$；
- 这个 $h_t$ 既用来产生当前的输出，又被传给下一个时间步。

普通的[神经网络](../neural-network/)是"一锤子买卖"——输入进、输出出，彼此独立。RNN 的关键不同是：**同一组权重被反复用在每个时间步上**，记忆通过 $h_t$ 在时间轴上流动。

## 数学表达

RNN 的核心是一条**递推公式**。设 $t$ 时刻的输入是 $x_t$，记忆是 $h_t$：

$$
h_t = \tanh\!\left(W_x\, x_t + W_h\, h_{t-1} + b\right)
$$

逐个符号解释：

- $x_t$：第 $t$ 个时间步的输入向量（比如某一天的销量、某个词的向量）。
- $h_{t-1}$：上一时间步的隐藏状态，也就是"到目前为止的记忆"。初始 $h_0$ 通常设为全 0。
- $h_t$：本时间步更新后的记忆。
- $W_x$：把输入 $x_t$ 映射进记忆空间的权重矩阵。
- $W_h$：把旧记忆 $h_{t-1}$ 变换后混入新记忆的权重矩阵。
- $b$：偏置向量。
- $\tanh$：[激活函数](../activation-function/)，把结果压到 $(-1, 1)$，给网络加入非线性。

输出（如果需要预测）一般再接一层：

$$
\hat{y}_t = W_y\, h_t + b_y
$$

注意：$W_x, W_h, W_y, b, b_y$ 在**所有时间步共享**——这就是"循环"二字的来历。一段长度为 100 的序列，并不是 100 套参数，而是同一套参数被用了 100 次。

## 时间反向传播（BPTT）与梯度消失

RNN 怎么学习？答案还是[反向传播](../backpropagation/)，只不过要沿着"时间"这条链条往回传，所以叫**时间反向传播**（BPTT, Backpropagation Through Time）。

把 RNN 沿时间"展开"，它就像一个很深的网络：第 $T$ 步的输出依赖 $h_T$，$h_T$ 依赖 $h_{T-1}$，一直串到 $h_1$。求梯度时，链式法则会把一长串导数连乘起来，其中反复出现这一项：

$$
\frac{\partial h_t}{\partial h_{t-1}} = W_h^{\top}\,\operatorname{diag}\!\big(\tanh'(\cdot)\big)
$$

要把 $T$ 步前的误差传回来，就要把这种因子连乘 $T$ 次，量级大致像 $\lambda^{T}$（$\lambda$ 是这些因子的"有效大小"）：

- 若 $\lambda < 1$，连乘后迅速趋近 0 → **梯度消失**，网络学不到远处的依赖（"忘了开头说过什么"）；
- 若 $\lambda > 1$，连乘后爆炸式增大 → **梯度爆炸**，训练数值不稳定。

这正是 [梯度消失 / 爆炸](../vanishing-exploding-gradient/) 问题在序列模型里的典型表现。$\tanh'$ 最大才 1、远离原点时接近 0，所以朴素 RNN 尤其容易梯度消失，**很难记住几十步以前的信息**。爆炸问题常用"梯度裁剪"缓解，消失问题则催生了 [LSTM](../lstm/)。

## 一个具体例子

用一个一维的迷你 RNN 走一遍数字，体会记忆是怎么累积的。设 $W_x = 0.5,\ W_h = 0.9,\ b = 0$，输入序列 $x = [1, 1, 1]$，$h_0 = 0$：

$$
\begin{aligned}
h_1 &= \tanh(0.5\times 1 + 0.9\times 0) = \tanh(0.5) \approx 0.462\\
h_2 &= \tanh(0.5\times 1 + 0.9\times 0.462) = \tanh(0.916) \approx 0.724\\
h_3 &= \tanh(0.5\times 1 + 0.9\times 0.724) = \tanh(1.152) \approx 0.818
\end{aligned}
$$

可以看到记忆 $h_t$ 在持续累积。下面是等价的 PyTorch 代码：

```python
import torch, torch.nn as nn

rnn = nn.RNN(input_size=1, hidden_size=8, batch_first=True)
x = torch.randn(4, 20, 1)        # (批大小=4, 时间步=20, 特征=1)
out, h_n = rnn(x)
print(out.shape)   # (4, 20, 8): 每个时间步的隐藏状态
print(h_n.shape)   # (1, 4, 8): 最后一步的隐藏状态
```

`out` 给出每一步的记忆，`h_n` 是序列读完后的"最终记忆"，常拿它接一层做预测。

## 在时间序列预测中的意义

RNN 曾是**时间序列预测的经典主力**：用过去若干天的观测一步步更新隐藏状态，再用最终状态预测未来。它能自然处理变长序列，也能建模时序依赖。

但它有两个硬伤：

- **必须按时间顺序逐步计算**，无法像卷积/注意力那样并行，长序列训练和推理都慢；
- **梯度消失**让它难以抓住很长的依赖关系，做长预测视野（long horizon）时尤其吃力。

这些局限推动人们转向能并行、能跨尺度建模的结构，比如 [Transformer](../transformer/) 和本站主打的多尺度模型 **Kernel U-Net（KUN）**——它借鉴 [U-Net](../u-net/) 的多分辨率思路，在不同时间尺度上提取并融合特征，从而既快又擅长长视野预测。

## 小结

- RNN 用共享权重的递推 $h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$ 维护一个随时间流动的记忆。
- 训练靠 **BPTT**；连乘导数导致**梯度消失/爆炸**，朴素 RNN 难记长依赖。
- 它顺序计算、不易并行，长序列效率低——这正是 [LSTM](../lstm/) 与多尺度模型 KUN 想解决的问题。
