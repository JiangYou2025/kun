**损失函数（loss function）** 是用来**衡量"模型预测"和"真实答案"之间差距**的函数。一句话：损失越小，预测越准；而**训练模型，本质上就是不断调整参数，把这个损失降到最低**。

## 直观理解

想象你在教一个学生做题。学生每做一题，你都给他打一个"扣分"：答得越离谱，扣得越多；答得越接近正确答案，扣得越少。这个**扣分规则**，就是损失函数。

- 它给模型一个**分数**，明确告诉模型："你现在错得有多严重。"
- 它还是**梯度下降（gradient descent）** 的**指南针**：模型不知道该往哪个方向调参数，但只要看看"损失朝哪个方向下降最快"，顺着那个方向走，就能越来越准。

所以损失函数有两个角色：既是**裁判**（打分），又是**向导**（指方向）。没有它，模型就像蒙着眼走路，根本不知道自己学得好不好、下一步该往哪迈。

## 数学表达

设我们有 $n$ 个训练样本 $(x_i, y_i)$，模型是 $f_\theta$（$\theta$ 表示所有可调参数），它对第 $i$ 个样本的预测是 $\hat y_i = f_\theta(x_i)$。**总损失**通常写成每个样本损失的平均：

$$\mathcal{L}(\theta)=\frac{1}{n}\sum_{i=1}^{n} \ell\big(y_i,\; f_\theta(x_i)\big)$$

逐个符号拆开看：

- $\theta$：模型的**参数**（比如线性模型里的权重和偏置）。训练就是找一组好的 $\theta$。
- $\ell(y_i, \hat y_i)$：**单个样本**的损失，衡量这一条预测错得多重。
- $\frac{1}{n}\sum$：把所有样本的损失**平均**起来，得到整体的"错误程度"。
- $\mathcal{L}(\theta)$：把它看成一个**关于参数 $\theta$ 的函数**——这正是梯度下降要最小化的对象。

不同任务，$\ell$ 的具体形式不一样。下面分回归和分类两大类来看。

## 回归损失：预测一个数值

当 $y$ 是连续数值（房价、气温、销量）时，常用下面几种。

**均方误差 MSE / 平方损失（squared loss）**：

$$\ell = (y-\hat y)^2$$

它把误差**平方**，所以**大误差会被放得特别大**（差 2 扣 4 分，差 10 扣 100 分）。优点是处处光滑、数学性质好、便于求导；缺点是**对异常点（outlier）非常敏感**——一个离谱的点就能把整体损失拉得很高，把模型"带偏"。

**平均绝对误差 MAE / 绝对损失（absolute loss）**：

$$\ell = |y-\hat y|$$

误差不平方，只取绝对值，所以**对异常点更鲁棒（robust）**：一个离群点不会被过度放大。代价是它在 $\hat y = y$ 处不可导（有个尖角），优化时需要特殊处理。

**Huber 损失**：在误差小的时候像 MSE（光滑），误差大的时候像 MAE（鲁棒），把两者的优点结合起来：

$$\ell_\delta(y,\hat y)=\begin{cases}\frac12 (y-\hat y)^2 & |y-\hat y|\le \delta\\[4pt]\delta\,\big(|y-\hat y|-\tfrac12\delta\big) & |y-\hat y|> \delta\end{cases}$$

$\delta$ 是切换点：误差在 $\delta$ 以内用平方（敏感、光滑），超出 $\delta$ 就转成线性（不被异常点带飞）。

## 分类损失：预测一个类别

当任务是分类（是猫还是狗、邮件是否垃圾）时，模型一般输出**概率** $\hat p$。这时最常用的是**交叉熵（cross-entropy）**。

多分类（$K$ 个类别，$y_k$ 是真实标签的 one-hot，$\hat p_k$ 是预测概率）：

$$\ell = -\sum_{k=1}^{K} y_k \log \hat p_k$$

二分类（$y\in\{0,1\}$，$p$ 是预测为正类的概率）：

$$\ell = -\big[\,y\log p+(1-y)\log(1-p)\,\big]$$

直觉：交叉熵奖励"对正确答案给出高概率"。如果真实是猫，而模型只给猫 0.1 的概率，那 $-\log 0.1$ 很大，狠狠扣分；如果给猫 0.99，$-\log 0.99$ 接近 0，几乎不扣。

**为什么用交叉熵，而不直接用"准确率"当损失？** 因为**准确率不可微**：它只在预测翻类的那一刻"跳变"，曲线是一级级台阶，梯度几乎处处为 0——模型微调参数时，准确率纹丝不动，梯度下降完全没法工作。交叉熵则是**平滑、可微**的，概率每动一点点，损失就跟着连续变化，能给出有用的梯度。这也引出一个关键要求 👇

## 为什么损失必须"可微"

基于梯度的训练（梯度下降及其各种变体）靠的是**对损失求导**，得到 $\nabla_\theta \mathcal{L}$，再让参数沿着让损失下降的方向更新：

$$\theta \leftarrow \theta - \eta\,\nabla_\theta \mathcal{L}(\theta)$$

这一步要成立，损失就必须（几乎处处）**可微（differentiable）**，导数才能告诉我们"往哪调、调多少"。这就是为什么我们用交叉熵而非准确率、用平方损失而非"对不对"这种 0/1 判断——**能优化的，必须先能求导**。

## 损失函数和别的概念怎么连起来

- **训练 = 最小化损失**：整个训练过程，就是用[梯度下降](../ml/)不断把 $\mathcal{L}(\theta)$ 往下推的过程。损失函数定义了"什么叫好"，优化算法负责"怎么变好"。
- **和正则化的关系**：[正则化](../regularization/) 就是在损失里**再加一个惩罚项** $\lambda\,\Omega(\theta)$，变成 $\mathcal{L}(\theta)+\lambda\,\Omega(\theta)$，逼模型别太复杂，从而抑制[过拟合](../overfitting/)。
- **损失函数 vs 评估指标**：这俩容易混。**损失函数是用来"优化"的**（要可微、训练时用），而[评估指标](../evaluation-metrics/) 是用来"汇报"的（给人看，可以不可微，比如准确率、F1、MAPE）。常见做法是：训练时优化交叉熵，最后向老板汇报准确率。两者方向一致，但不是同一个东西。

## 一个具体的小例子

用平方损失手算一下，感受"大误差被放大"。三个样本，真实值和预测值如下：

```python
y      = [3.0, 5.0, 10.0]
y_hat  = [2.5, 5.5,  7.0]   # 前两个差 0.5，最后一个差 3

errors = [yi - pi for yi, pi in zip(y, y_hat)]   # [0.5, -0.5, 3.0]
mse = sum(e**2 for e in errors) / len(errors)    # (0.25+0.25+9)/3 = 3.17
mae = sum(abs(e) for e in errors) / len(errors)  # (0.5+0.5+3)/3   = 1.33
```

注意那个差了 3 的点：在 MAE 里它贡献 3，在 MSE 里它贡献 $3^2=9$——**MSE 把这个大误差放大得多**，所以最小化 MSE 的模型会更努力去照顾这个离群点。

## 在时间序列预测中的意义

时间序列预测里，损失函数的选择直接关系到"模型在乎什么":

- **MSE**：因为放大大误差，它会**重点惩罚那些预测错得离谱的尖峰（spike）**。如果你最怕的是"偶尔大错一次"（比如电力调度），MSE 合适。
- **MAE**：对**异常点 / 离群波动更鲁棒**。如果你的序列里常有突发噪声、个别离谱值，又不想被它们带偏，MAE 更稳。
- **分位数损失 / Pinball Loss（quantile loss）**：当你不只想要一个点预测，而是想做**概率预测 / 区间预测**（"明天销量有 90% 概率落在某区间内"）时，用分位数损失。它对第 $\tau$ 分位数的定义是：

$$\ell_\tau(y,\hat y)=\max\big(\tau\,(y-\hat y),\;(\tau-1)(y-\hat y)\big)$$

它**不对称地惩罚高估和低估**：取不同的 $\tau$（如 0.1、0.5、0.9）分别训练，就能画出预测区间的上下界。

核心原则一句话：**选损失，要匹配你犯错的代价**。低估库存和高估库存代价不同？那就别傻用对称的 MSE，换上不对称的分位数损失。

## 小结

- **损失函数**衡量预测与真值的差距，是训练的**裁判 + 指南针**；训练 = 最小化损失。
- 总损失 $\mathcal{L}(\theta)=\frac1n\sum_i \ell(y_i, f_\theta(x_i))$，$\ell$ 因任务而异。
- 回归：**MSE** 放大大误差、对异常点敏感；**MAE** 鲁棒但有尖角；**Huber** 折中。
- 分类：**交叉熵**平滑可微，远胜不可微的准确率。
- 损失必须**可微**，梯度下降才能工作。
- **损失（优化用）≠ 评估指标（汇报用）**；[正则化](../regularization/)是给损失加惩罚项。
- 时间序列：MSE 治尖峰、MAE 抗异常、**分位数损失**做区间预测——按犯错代价来选。
