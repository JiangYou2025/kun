**聚类（clustering）** 是一种**[无监督学习](../unsupervised-learning/)**方法：在没有标签的情况下，把彼此相似的样本自动分到同一组（簇）里，让"组内尽量相似、组间尽量不同"。

## 直观理解

想象你拿到一大堆超市的销售记录，但没有人告诉你哪些店属于"市中心大店""郊区小店""节假日爆发型"。聚类要做的，就是**让数据自己说话**：根据各个样本在特征空间里的"远近"，把挨得近的点归成一堆。

这里的关键词是**相似度**，通常用**距离**来衡量。两个样本越接近，就越可能属于同一簇。最常用的是**欧氏距离**：

$$d(x, y) = \sqrt{\sum_{i=1}^{p}(x_i - y_i)^2}$$

其中 $x, y$ 是两个样本（各有 $p$ 个特征）。和**[监督学习](../supervised-learning/)**（有标准答案）不同，聚类没有"正确的分组"，结果好不好要靠业务含义和指标共同判断。

## 原理：K-means [算法](../algorithms/)

最经典、最常用的聚类算法是 **K-means（K 均值）**。你需要先指定簇的个数 $k$，然后算法不断迭代：

1. **随机初始化** $k$ 个中心（质心，centroid），可以随机挑 $k$ 个样本点当起点；
2. **分配**：把每个点分给离它**最近的中心**所代表的簇；
3. **更新**：把每个簇的中心重新计算为**该簇所有点的均值**；
4. **重复**第 2、3 步，直到中心不再明显移动（**收敛**）。

直观上，这是一个"分配—更新"反复拉扯的过程：点跟着最近的中心走，中心又被自己手下的点拉到平均位置，最终达到稳定。

### 它在最小化什么

K-means 其实在最小化**簇内平方和（within-cluster sum of squares, WCSS）**，也叫**惯性（inertia）**：

$$J = \sum_{j=1}^{k}\sum_{x\in C_j}\|x-\mu_j\|^2$$

逐个符号解释：

- $k$：簇的总个数（你指定的）；
- $C_j$：第 $j$ 个簇里所有样本的集合；
- $x$：属于簇 $C_j$ 的一个样本（向量）；
- $\mu_j$：第 $j$ 个簇的中心，等于该簇所有 $x$ 的均值；
- $\|x-\mu_j\|^2$：样本到它所属中心的**欧氏距离的平方**；
- 双重求和：先在每个簇内把所有点到中心的平方距离加起来，再把所有簇加总。

$J$ 越小，说明每个簇里的点都紧紧围着自己的中心，聚得越"瓷实"。"分配"步骤让每个点选最近的中心、"更新"步骤把中心放到均值处——这两步都在让 $J$ 下降，所以算法一定会收敛（但可能收敛到**局部最优**，因此常用不同初始化多跑几次取最好的，sklearn 默认就这么做）。

## 如何选择 k

$k$ 要自己定，怎么定才合理？两个常用工具：

- **肘部法（elbow method）**：把不同 $k$ 对应的 $J$（inertia）画成曲线。$k$ 越大 $J$ 越小，但下降会越来越慢；曲线出现明显"拐弯"（像手肘）的那个 $k$，往往是性价比最高的选择。
- **轮廓系数（silhouette coefficient）**：对每个样本计算 $s = \dfrac{b - a}{\max(a, b)}$，其中 $a$ 是它到**同簇**其他点的平均距离，$b$ 是它到**最近的其他簇**的平均距离。$s$ 越接近 1 说明分得越好，接近 0 说明在边界上，为负说明可能分错了。取所有样本的平均轮廓系数最高的 $k$。

## 一个具体例子

用 scikit-learn 跑一遍 K-means（注意**先标准化**）：

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X = np.array([[1.0, 2.0], [1.2, 1.8], [5.0, 8.0],
              [5.2, 8.1], [9.0, 1.0], [8.7, 1.2]])

# 1) 标准化：让每个特征均值为 0、方差为 1，避免量纲大的特征主导距离
X_scaled = StandardScaler().fit_transform(X)

# 2) 训练 KMeans，n_init=10 表示用 10 套不同初始化取最好结果
km = KMeans(n_clusters=3, n_init=10, random_state=0)
labels = km.fit_predict(X_scaled)

print("每个样本的簇标签:", labels)        # 例如 [0 0 1 1 2 2]
print("簇中心:", km.cluster_centers_)
print("簇内平方和 (inertia):", km.inertia_)
print("轮廓系数:", silhouette_score(X_scaled, labels))
```

`fit_predict` 返回每个样本属于哪个簇；`inertia_` 就是上面的 $J$；`silhouette_score` 帮你评估这个 $k$ 选得好不好。

## 局限性与其它方法

K-means 简单高效，但要注意它的假设：

- **假设簇是"球状"且大小相近**：对于细长、环形或密度差异很大的簇，K-means 会分得很糟；
- **对初始化敏感**：可能陷入局部最优（用 `k-means++` 初始化和多次 `n_init` 缓解）；
- **对尺度敏感**：距离由数值大的特征主导，所以**必须先标准化特征**；
- **必须事先指定 $k$**，对离群点也比较敏感。

替代方案：

- **层次聚类（hierarchical clustering）**：不需要预先定 $k$，通过不断合并（或拆分）形成一棵"树状图（dendrogram）"，你可以在任意高度"切一刀"得到想要的簇数，适合想观察嵌套结构的场景。
- **DBSCAN**：基于**密度**聚类，能发现任意形状的簇，并自动把稀疏区域的点标为**噪声/离群点**，不需要指定 $k$，但要调好邻域半径等参数。

## 在时间序列预测中的意义

聚类在时序预测里非常实用：

- **相似序列共享模型**：把行为相似的门店、传感器、用户分成几类，每一类训练一个模型（而不是给成千上万条序列各训一个），既省算力又更稳健；
- **识别状态/区制（regime）**：把不同时间段按特征聚类，区分"平稳期 / 高波动期 / 促销期"等**区制**，便于分段建模；
- **作为特征**：把**簇 id** 作为一个类别特征喂给下游预测模型，让模型知道"这条序列属于哪一类"。

几点提醒：聚类前**一定要先标准化**；对原始时序波形，普通欧氏距离未必合适，可考虑**动态时间规整（DTW）**这类对齐距离，或先提取统计特征（均值、波动、趋势、周期强度）再聚类。

## 小结

- **聚类**是无监督地把相似样本分组，靠**距离/相似度**衡量远近。
- **K-means** 通过"分配最近中心—更新为簇均值"反复迭代，最小化**簇内平方和** $J=\sum_j\sum_{x\in C_j}\|x-\mu_j\|^2$。
- 选 $k$ 常用**肘部法**和**轮廓系数**；务必**先标准化**特征。
- K-means 假设球状簇、对初始化和尺度敏感；**层次聚类**和 **DBSCAN** 是常见替代。
- 在时序预测中可用来**聚相似序列共享模型**、**识别区制**、**当作特征**——记得先标准化、选对距离。
